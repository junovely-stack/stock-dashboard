# 시장 일지 · 복기 시스템 — 정리된 프롬프트

원래 아이디어를 두 가지 프롬프트로 정리했다.
**A는 이 시스템을 만들거나 고칠 때** Claude에 주는 프로젝트 정의서. **B는 매일/매주 복기할 때** `briefing.md`와 같이 붙여넣는 프롬프트.

---

## A. 프로젝트 정의 프롬프트 (만들 때·고칠 때)

```
[목적]
증권사 직원들이 매일 일일동향·외국인 수급을 보고 판단하듯, 나도 매일 시장 상태와 내 판단을 기록하고
나중에 복기해서 "어떤 상태일 때 이후 어떻게 됐나"를 근거로 매수 타이밍을 잡고 싶다.
주 투자 대상은 코인(BTC·알트), 보조로 미국·한국 주식(특히 중소형주).
글로벌·매크로 이슈로 급등락이 나올 때 미리 대비하고, 조건이 맞을 때 먼저 사고 싶다.
예: "알트 강도가 X일 때 이후 30일 알트시장은?", "달러 강세 + 공포 구간이면 중소형주는?"

[시스템이 할 일]
1. 매일 자동 수집 (사람 손 0)
   - 코인: BTC, ETH, 알트 20종 바스켓, 공포탐욕지수, 스테이블코인 공급, 김치프리미엄, BTC 도미넌스
   - 매크로: 달러인덱스, 미 10년물, VIX, 금, 유가, 원달러
   - 주식: S&P500, 나스닥, 러셀2000(미 중소형), 코스피, 코스닥(한 중소형)
   - 2017년부터 백필해서 첫날부터 과거 통계를 쓸 수 있게
2. 지표 → 구간(상태) 분류 → "과거에 이 구간이었을 때 이후 7일/30일 수익률 분포"
   - 반드시 기저율(조건 없을 때)과 같이, 표본 수와 독립 표본 수(n/기간)를 같이
3. "지금과 비슷했던 날": 여러 지표 구간이 동시에 같았던 날짜와 그 뒤 성적, 구간(에피소드) 목록
4. 내 일지: 느낌(1~5), 예측 1개(대상·방향·기간·확신도), 근거 한 줄, 행동
   - 30초 안에 폰으로 쓸 수 있어야 함
   - 기간이 지나면 실제 수익률로 자동 채점 → 적중률, 확신도 보정, "내 느낌별 이후 성적"
5. 매일 브리핑 텍스트 생성 → Claude에 붙여넣어 해석만 받음

[원칙]
- 숫자 계산은 코드가 한다. LLM은 해석만.
- 예측이 아니라 기저율이다. 조건부 통계는 항상 기저율 옆에.
- 없는 값은 만들지 않는다. 미연동은 "연동 대기", 실패는 "과거값"으로 표시.
- 화면 상단에 데이터 기준일·수집 시각·소스별 상태 고정.
- 사후 기록·늦은 수정은 적중률 집계에서 제외(결과를 알고 쓰면 복기가 아니라 합리화).
- 생존 편향(지금 살아남은 알트만 바스켓에 들어감)과 겹치는 표본 문제를 화면에 명시.

[환경]
GitHub 저장소 + GitHub Actions(매일 KST 09:20) + GitHub Pages. 서버·DB·유료 API 없음.
일지 입력은 GitHub 이슈 폼 → Actions가 JSON으로 저장·채점·댓글.
```

## B. 복기 프롬프트 (매일 30초 / 주 1회 10분)

`journal.html` 상단 **브리핑 텍스트** 링크(= `data/journal/briefing.md`)를 통째로 복사해 아래 프롬프트 뒤에 붙인다.

### 매일 (아침, 일지 쓰기 전)

```
아래는 내 시장 일지 시스템이 오늘 계산한 브리핑이다. 숫자는 이미 계산돼 있으니 다시 계산하지 말고 해석만 해줘.

1. 오늘 상태를 한 줄로: 기저율 대비 유의하게 벗어난 지표만 골라서(상승확률 차이 5%p 이상 + 독립표본 10 이상).
   표본 부족·참고용 지표는 "참고"로 따로 빼.
2. "지금과 비슷했던 날" 결과가 기저율과 같은 방향인지, 반대인지. 구간 수가 5개 미만이면 그 사실부터 말해.
3. 지표끼리 엇갈리는 부분(예: 공포탐욕은 매수, 달러는 역풍) 1~2개.
4. 오늘 내가 예측을 쓴다면 스스로 점검할 질문 2개. 방향을 정해주지는 마.

금지: 과거 통계를 "~할 것이다"로 단정하기, 브리핑에 없는 숫자 만들기, 뉴스 추측.

[브리핑]
(여기에 briefing.md 붙여넣기)
```

### 주 1회 (일요일, 채점 결과 보면서)

```
아래 브리핑의 "내 일지" 부분을 복기해줘. 해석만, 계산 새로 하지 말 것.

1. 이번 주 채점된 예측 중 빗나간 것: 기록 시점 시장 상태(공포탐욕·알트강도·200일선)와 내 근거를 비교해서
   내가 무시한 신호가 있었는지.
2. 확신도 보정: 확신 70~90%로 쓴 것의 실제 적중률이 말한 확신보다 낮은가(과신) 높은가(과소).
   건수가 5건 미만이면 판단 보류라고 말해.
3. 내 느낌(1~5)과 공포탐욕지수가 크게 엇갈린 날이 있었나. 그날 결과는?
4. 다음 주에 바꿔볼 습관 1개. 구체적으로 (예: "확신 90%는 2개 이상 지표가 같은 방향일 때만").

[브리핑]
(여기에 briefing.md 붙여넣기)
```

### 월 1회 (패턴 찾기, 일지 30건 이상일 때부터)

```
아래 브리핑과 일지 목록을 보고 "내가 잘 맞히는 상황 / 못 맞히는 상황"을 찾아줘.
대상(BTC/알트/주식)·기간(7/30일)·기록 시점 시장 구간·태그(FOMC, CPI 등)별로 나눠 보되,
각 그룹 건수를 같이 쓰고 5건 미만 그룹은 결론 내지 마.
마지막에 내 판단을 믿어도 되는 조건 1개, 시스템 통계를 믿어야 하는 조건 1개.
```
