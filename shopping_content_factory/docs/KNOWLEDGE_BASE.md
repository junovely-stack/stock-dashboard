기준일 2026-11-21 · 인터랙티브: [SCF_지식체계_REV01.html](SCF_지식체계_REV01.html) · 진행 현황: [PROGRESS.md](PROGRESS.md) · 도메인 지도: [SCF_온톨로지_REV02.html](SCF_온톨로지_REV02.html)

## 왜 있나

지금까지 만든 것(요구서·코드·테스트·조사·판단·결정·가상 운영)이 문서 19종에 흩어져 있다. 이를 **클래스 18개와 관계 유형 24개**로 묶어, "무엇이 무엇의 근거이고, 무엇이 무엇을 막고 있는지"를 한 그래프에서 따라갈 수 있게 한다. 도메인 온톨로지(개념 36·관계 60)는 이 지식체계의 한 층(도메인 개념)이다.

## 세 층

| 층 | 클래스 | 답하는 질문 |
|---|---|---|
| 목표·진행 | 산출물 · 완료 기준 · 단계 · 기획 수정안 | 무엇을 만들기로 했고, 어디까지 왔나 |
| 시스템 | 도메인 개념 · 구현 요소 · 검증 · 증거 · 문서 · 자동화 액션 | 무엇이 어떻게 구현되고 무엇으로 확인했나 |
| 판단 근거 | 외부 주체 · 사실 · 정책·규정 · 가정 · 리스크 · 결함·약점 · 결정 · 지표 | 무엇을 근거로 판단하고, 무엇이 막고 있나 |

SPARQL 예시 (rdflib·Protégé 등에서 실행):

```sparql
PREFIX scf: <https://example.invalid/scf/ontology#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
# 완료 기준에 단서를 만든 미해결 결함
SELECT ?defect ?label ?criterion WHERE {
  ?defect a scf:Defect ; scf:status "open" ; rdfs:label ?label ; scf:affects ?criterion .
  ?criterion a scf:Criterion .
}
```

```sparql
PREFIX scf: <https://example.invalid/scf/ontology#>
```
