# 컴플라이언스 체크리스트

✅ = 코드로 강제(위반 시 차단) · 🖐 = 사람이 확인(승인 화면에 표시) · ⏳ = 운영 전 원문·전문가 확인 필요.
법률 자문이 아니다. 출처와 확인 수준은 [API_ACCESS_MATRIX.md](API_ACCESS_MATRIX.md).

## 1. 경제적 이해관계 표시 (공정위 「추천·보증 등에 관한 표시·광고 심사지침」 2024-12-01 개정, 2026-06-01 AI 가상인물 추가)

| 요구 | 우리 처리 | 코드 |
|---|---|---|
| 한글로 명확하게, 확정형으로. "수수료를 지급받을 수 있음" 같은 조건부 표현은 명확한 표시가 아님 | ✅ 표시 문구에 "받을 수 있", "AD", "PR" 등 들어가면 차단 | `services/affiliate_links/links.py::check_disclosure_text` |
| 영상 전체가 추천·보증이면 시작과 끝에 표시하고 중간에도 반복 | ✅ 전 장면 좌상단 '광고' 배지 + 첫 장면 문구 + 마지막 장면 전체 문구 | `services/video_renderer/renderer.py` |
| 제목에 표시하면 모바일에서 잘리지 않게 | ✅ 유튜브 제목 맨 앞 `[광고]` | `fact_guard: disclosure_title` |
| SNS 캡션은 첫 부분에, '더보기' 뒤·댓글·링크 뒤는 부적절 | ✅ 캡션 첫 줄이 표시 문구가 아니면 차단 | `fact_guard: disclosure_caption` |
| 해시태그로 표시하면 첫 해시태그 | ✅ 첫 해시태그 `#광고` | `fact_guard: disclosure_hashtag` |
| 구매 링크 수수료는 공개 대상 | ✅ 랜딩 상단·버튼 옆·푸터 고지 | `app/templates/public/*` |
| AI 가상인물 등장 시 '가상인물' 표시 | 🖐 MVP 는 AI 인물 미사용. 쓰게 되면 표시 필수 | `config/compliance.toml: virtual_person_label` |
| 쿠팡 요구 문구 모든 게시물에 쉽게 보이게 | ✅ "이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." ⏳ 최신 표기 확인 | `config/compliance.toml` |

요구서 예시 문구("…수수료를 제공받을 수 있습니다")는 위 조건부 표현에 해당할 소지가 있어 **사용하지 않는다.**

## 2. 표시·광고 내용의 사실성

| 요구 | 우리 처리 |
|---|---|
| 검증되지 않은 효과 주장 금지 | ✅ 숫자+단위 주장은 검증 사양과 일치해야 통과(5kg 사양에 10kg 자막 → 차단). 효과 주장이 필요한 상품은 후보 단계에서 제외 |
| 가격 표시 정확성 | ✅ 영상·캡션에 금액·할인율 금지. 랜딩은 확인 시각과 함께, 24시간 지나면 숨김. 가격 만료 시 게시 차단 |
| 거짓 희소성·허위 할인·가짜 후기·조작된 판매량 | ✅ 금칙어 차단(품절 임박, 오늘만, 리뷰 1만, 판매량 1위 등) |
| 최상급·절대 표현, 근거 없는 비교 | ✅ 금칙어 차단(최저가, 1위, 100%, 타사 대비 등) |
| 써보지 않은 상품의 경험 주장 | ✅ "써보니·내돈내산" 등은 `own_usage_verified=true` 일 때만 허용 |
| 사실 아닌 사용 전후 비교 | ✅ 전후 비교 이미지 생성 안 함, 장면은 '연출 일러스트' 표기 |
| 승인 후 상품 정보 변경 | ✅ 사실 해시가 바뀌면 게시 차단(재생성·재승인) |
| 승인 후 영상 파일 변조 | ✅ 해시 불일치 시 게시 차단 |
| 품절 상품 게시 | ✅ 재고 품절·판매중지면 게시 차단, 랜딩 구매 버튼 숨김 |
| 위험·규제 상품(의약외품·건강기능식품·전열기·락스 등) | ✅ 후보 단계 제외 (`config/compliance.toml: excluded`) |

## 3. 제휴 프로그램 운영 (쿠팡파트너스)

| 항목 | 상태 |
|---|---|
| 임의 URL 생성 금지 — 생성 못 하면 수동 등록 | ✅ |
| 링크 정상 여부 확인을 위해 자동으로 링크 열지 않음(클릭 오염·부정 클릭 소지) | ✅ 형식 검증 + 사람 확인 |
| 자동 리디렉션·숨은 iframe·쿠키 삽입 금지 | ✅ 랜딩 버튼은 일반 `<a rel="sponsored nofollow noopener">`, 이벤트는 sendBeacon 기록만 |
| 본인 링크로 구매 금지(실적 제외) | 🖐 운영 수칙 |
| 쿠팡 키워드 검색광고·쿠팡 상표 도메인 금지 | ⏳ 2021 보도 기준, 현행 약관 확인 |
| 링크 단축·리디렉션 서비스 | ⏳ 약관 확인 전까지 사용 안 함 |
| 상품 이미지 사용·편집 범위 | ⏳ 확인 전까지 영상 사용 차단(`SCF_ALLOW_PARTNER_IMAGES_IN_VIDEO=false`), 랜딩은 원본 표시만 |

## 4. 플랫폼 정책

| 플랫폼 | 요구 | 상태 |
|---|---|---|
| Meta | 제3자 제휴 수수료 게시물 → '유료 파트너십' 라벨 사용 안내 | 🖐 API 지정 가능 여부 미확인 → 승인 체크리스트·`content_manifest.manual_steps` |
| Meta | 실사형 AI 영상·음성은 AI 공개 | ✅ AI 생성 미디어 포함 시 `is_ai_generated=true` |
| Meta | 원본성: 동일 콘텐츠는 원본만 추천, 반복 재게시 계정 추천 제외 | ✅ 같은 상품 30일 금지·새 정보 없으면 제외 |
| YouTube | 유료 프로모션 표시 | ✅ `hasPaidProductPlacement=true` 명시, 거절 시 🖐 Studio 수동 체크 |
| YouTube | 실사형 합성 고지 | ✅ `containsSyntheticMedia` |
| YouTube | 진정성 없는 콘텐츠(템플릿 대량생산) 수익화 정책 | 🖐 하루 생성 상한, 장면 문구가 상품마다 달라야 함 |
| YouTube | Shorts 설명란 링크 클릭 불가 | ✅ CTA 를 '채널 프로필 링크'로 |

## 5. AI 관련 법규

- **AI 기본법(2026-01-22 시행)**: 표시 의무 주체는 '인공지능사업자'. 과기정통부 가이드·상담 사례상 AI 를 도구로 쓰는 개인 창작자는 표시 의무 없음(공식 법령해석 아님). ⏳
- **정보통신망법 AI 생성물 표시 개정안**: 2026-01 발의, 2026-10-29 보도 기준 미통과 → 통과 시 즉시 반영 필요. ⏳
- 그와 별개로 플랫폼 규정(Meta·YouTube)과 공정위 가상인물 규정은 적용.

## 7. 세무·사업자

- 쿠팡파트너스 개인 수익 = 사업소득, 원천징수 후 지급(세율 ⏳). 종합소득세 신고 대상.
- 계속·반복 수익 → 사업자등록 필요 여부, 통신판매업 신고 필요 여부(직접 판매 아님) ⏳ 세무사 확인.
- 시뮬레이션 세율 6.6% 는 **가정**(종합소득세 최저구간 + 지방세).
