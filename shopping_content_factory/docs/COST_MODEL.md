## 2. 월 고정·준고정 비용

| 항목 | 필요한 이유 | 금액 |
|---|---|---|
| 공개 웹 호스팅 | 랜딩 페이지 + **Instagram 은 공개 URL 의 영상을 가져가야 게시 가능** | 입력 필요 (요금제 미확인) |
| 도메인 | 프로필 링크용 짧은 주소 | 입력 필요 |
| 객체 저장소(선택) | 영상 공개 URL 을 웹서버와 분리할 때 | 입력 필요 |
| 상품 샘플 구매(선택) | 실촬영 콘텐츠 — 신뢰·원본성에 가장 유리 | 상품가(예: 19,900원/개) — **가장 큰 변동비** |
| 사용자 가정 월 운영현금비 | 위 항목 합산 자리 | 250,000원 (가정) |

상품 샘플 구매는 AI 비용보다 두 자릿수 크다. 19,900원 상품의 주문당 수수료는 약 600원 → 샘플 1개를 회수하려면 그 상품으로 약 33건이 팔려야 한다. 실촬영은 이미 가진 물건, 반응이 확인된 상품부터.

## 3. 노동비

사용자 가정 30시간/월 × 25,000원 = 750,000원. 현금비의 3배로 **수익성의 최대 변수**. 관리자 화면에서 검수·게시에 쓴 시간을 따로 기록해 실측으로 바꿀 것(현재는 감사 로그 시각으로 추정 가능).

## 4. 이번 작업에서 발생한 비용

- 외부 유료 API 호출: **0건, 0원** (전 구간 mock·로컬 렌더링). 유료 API 활성화·계정 설정·게시는 하지 않음.
- 개발 환경 비용(이 세션의 모델 사용료)은 이 표의 운영 비용과 별개.

## 5. 손익 연결

운영 비용 합계는 `config/finance.toml` 의 `monthly_cash_opex_krw` 로 들어가 [ROI_REPORT.md](ROI_REPORT.md) 손익분기 계산에 쓰인다. 실제 지출은 관리자 `로그·비용` 화면에서 분류별(ai_api / video / server / product_sample / other)로 입력 → 성과 화면의 콘텐츠별 실측 손익에 반영.

## 6. LLM 모델 선택지 (D9, REV02 추가)

추정 토큰(콘텐츠당 입력 8,500 / 출력 6,500 — `config/costs.toml [estimate]`) × 단가(Anthropic 공식 가격표, 2026-11-03 캐시) × 1,400원/$. 생각(thinking) 토큰은 출력으로 과금되므로 실제는 2~3배까지 늘 수 있다 — 첫 1주 `api_usage` 실측으로 교체.

| 모델 | 입력 / 출력 ($/100만 토큰) | 콘텐츠당 | 월 30개 | 비고 |
|---|---|---|---|---|
| Claude Opus 5.5 (현재 기본값) | 4 / 20 | 약 230원 | 약 6,900원 | 품질 우선 |
| Claude Sonnet 5.5 | 2 / 10 | 약 115원 | 약 3,400원 | |
| Claude Haiku 5.5 | 0.10 / 0.50 | 약 6원 | 약 170원 | 10만 토큰 이하 프롬프트 기준 단가 |
| 규칙 기반(mock) | — | 0원 | 0원 | 리서치 메모를 사람이 씀 → 노동비로 전가 |

어느 모델이든 월 상한(`SCF_COST_CAP_MONTHLY_KRW=50000`) 안이다. 비용보다 **사람 리서치 시간을 얼마나 줄이는지**가 판단 기준.
