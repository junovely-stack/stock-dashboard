> 대상: 조립부(조립1~4과) 생산관리 실무 + 사내 AI 에이전트 컨텍스트
> 기준일: 2026-09 · 검증등급 표기: `[E]` 외부검증 / `[G]` 업계통용 / `[C]` 사내확정 / `[?]` 사내확인필요

## 1. 전체 흐름 — 조립은 어디에 끼어 있는가

```
강재 입고
  └ 전처리 (쇼트블라스트 + 프라이머)              [E]
      └ 가공 (NC 절단 → 개선가공 → 벤딩/프레스/롤링)  [E]
          └ ■ 소조립  (부재 + 부재)                  ← 조립부
              └ ■ 중조립 (소조품 + 판 = 평블록)       ← 조립부
                  └ ■ 대조립 (입체블록 / 곡블록)      ← 조립부
                      └ 곡직 · 정도검사 · 선주검사     ← 조립부 (공정 내 삽입)
                          └ 도장 (블라스팅 + 도장)
                              └ PE (Pre-Erection, 지상 대조합)
                                  └ 탑재 (도크) → 진수 → 안벽 → 시운전 → 인도
```

조립부의 범위는 **"가공품이 들어와서 도장 가능한 블록으로 나가기까지"**. 조립 공정은 선형이 아니라 정반 위에서 `배재 → 취부 → 용접 → 사상 → 곡직 → 검사`가 겹쳐 돌아간다. 같은 정반에서 앞 블록 사상 중에 다음 블록 부재가 배재될 수 없으므로, **정반 점유가 곧 능력**이다. 이게 조립 생산관리의 출발점.

### 1-1. 생산관리가 실제로 보는 것

| 보는 것 | 왜 | 데이터 출처 |
|---|---|---|
| 정반 점유 / 회전 | 공장 능력의 실질 상한 | `[?]` MES 정반 배정 테이블 여부 |
| 블럭 입/반출일 | 공정 진도·기성 인식 기준점 | `[?]` 입고일·반출일 컬럼 확인 |
| 검사 A/R | 당일검사완료율의 분자·분모 | 구조 검사신청 파일 (운영 중) |
| 용접 검사길이·불량길이 | 용접불량률 | 용접불량률 파일 (운영 중) |
| 정도 합/불 | 정도불량률 | 정도불량률 파일 + 물량정보 마스터 |
| 완료 블록 수 × 블럭당 금액 | 기성 | `[?]` 완료 판정 시점 정의 |

## 2. 블럭 입/반출 — 공정관리의 시계(時計)

### 2-1. 정의

- **입고(입고/투입)**: 전 공정 산출물이 우리 공장 정반 또는 야드 적치장에 들어오는 이벤트. 소조는 가공 부재, 중조는 소조품+판, 대조는 중조품(평블록)+부재가 입고된다. `[G]`
- **반출(출고)**: 자기 공정 완료물을 후행(중조/대조/도장/PE/적치장)으로 내보내는 이벤트. `[G]`
- 두 이벤트는 **물리 이동**이면서 동시에 **정반 점유의 시작·종료 신호**다. 생산관리에서 입/반출 데이터가 중요한 이유는 이동 그 자체가 아니라 이 점유 구간 때문.

### 2-2. 운반 수단

| 수단 | 범위 | 특징 | 등급 |
|---|---|---|---|
| O.H.C (천장크레인) | 공장 건물 내부 | 실내 양중 전담. 5장 참조 | `[E]` |
| 골리앗/갠트리 크레인 | 도크·PE장·야외 정반 | 지상 레일 + 다리 구조. 대형 중량 | `[E]` |
| 트랜스포터 (T/P, MT) | 야드 전체 | 자주식 다축 대차. 유류·경로비용이 실제 돈으로 잡힘 | `[E]` |
| 대차 / 롤러 / 스키드 | 공장 내 라인 이동 | 라인정반의 흐름 이동 수단 | `[G]` |
| 턴오버 장치 / 포지셔너 | 블록 반전·경전 | 크레인 2대 합체 양중을 대체 → 크레인 대기·안전 리스크 감소 | `[E]` |

> 참고: 대형 포지셔너·턴오버 장치·트랜스포터 같은 물류·세팅 설비는 생산능력 자체를 늘리지는 않지만 **크레인 대기시간과 안전 리스크를 줄여 공장 회전율을 올린다.** 조립 공장 투자 검토 시 이 논리를 쓴다. `[E]`

### 2-3. 반전(턴오버) — 조립 특유의 함정

평블록·곡블록은 한쪽 면 용접 후 뒤집어 반대면을 용접한다. 반전에는 크레인 2대 동시 작업 또는 턴오버 장치가 필요하고, 그 순간 다른 블록 양중이 막힌다.

- 반전 횟수가 많은 블록 = 크레인 점유가 큰 블록 = **난이도 점수에 반영되어야 하는 블록.** `[?]` 현재 난이도 점수 산식에 반전 횟수가 들어가는지 확인 필요.
- 반전 전에 족장·서포트·지그를 정리해야 하므로 준비 공수가 별도로 붙는다. `[G]`

### 2-4. 입/반출이 공정을 죽이는 경로

```
후행 공정 적체 (도장 대기 / PE 대기)
   → 반출 못 함
      → 정반 점유 지속
         → 다음 블록 입고 불가
            → 배재·취부 인력 유휴 or 타 정반 과밀
               → 월말 몰림 → W.L 일괄 인식 → 주간 생산성 착시
```

마지막 줄이 지표 왜곡의 실제 원인이다. **주차 변동보다 월 집계를 우선하는 근거가 여기 있다.** 공기 긴 대형 블록은 완료 시점에 W.L이 한꺼번에 인식되므로, 주간 그래프의 골과 봉우리는 대개 생산성 변화가 아니라 인식 시점의 문제다.

## 3. 소조립 · 중조립 · 대조립

### 3-1. 세 단계의 실체

| | 소조립(小組立) | 중조립(中組立) | 대조립(大組立) |
|---|---|---|---|
| 투입물 | 가공 부재 (최소 2 Piece 이상) | 소조품 + 외판/내판 | 중조품(평블록) + 부재 + 소조품 |
| 산출물 | 부분 구조체 | 평블록 (Flat Block) | 입체블록 / 곡블록 |
| 대표 부재·블록 | 거더, 플로어, 웹, 론지, 브라켓, 스티프너 | 선체 중앙부 평블록, 외판·격벽 판 블록 | 선수, 선미, 엔진룸, 데크하우스, 곡블록 |
| 형상 | 2D 또는 얕은 3D | 평면 중심 | 입체 (내부 진입 필요) |
| 정반 | 라인정반 중심 | 라인정반 / 패널라인 | 고정정반(핀지그) 중심 |
| 자동화 | 높음 (로봇·전용기) | 중간 (패널라인 자동용접) | 낮음 (수동 비중 큼) |
| 등급 | `[E]` | `[E]` | `[E]` |

> 규모 감각: 소조가 블록 한 곳의 귀퉁이를 만드는 것이라면, 중조·대조는 블록 하나 또는 블록들의 집합을 만드는 것. `[E]`

### 3-2. 단계가 올라갈수록 무엇이 변하는가

| 축 | 소조 → 대조 방향 |
|---|---|
| 피스 수 | 많음 → 적음 |
| 단위 중량 | 가벼움 → 무거움 |
| 입체도 | 평면 → 입체 (밀폐구역 발생) |
| 용접 자세 | 아래보기 위주 → 수직·위보기 증가 |
| 자동용접 적용률 | 높음 → 낮음 |
| 불량률 리스크 | 낮음 → 높음 (자세·접근성 때문) |
| 곡직 필요성 | 낮음 → 높음 (누적 변형) |
| 선주검사 강도 | 낮음 → 높음 (내부검사·밀폐구역 검사 발생) |
| 공기(리드타임) | 짧음 → 김 |

**지표 설계 시 함의**: 소조와 대조를 같은 "블록 1개"로 세면 안 된다. 대조립 1블록과 소조립 1블록의 공수 차이는 수 배다. 그래서 `블럭당 난이도 = 난이도 점수합 ÷ 완료블럭 수`가 일당 난이도보다 유효하다. 단계·형상·반전 횟수·밀폐구역 유무가 난이도 점수에 반영되어야 한다. `[?]` 현재 점수 항목 구성 확인 필요.

### 3-3. 단계 구분의 실무 경계

소/중/대 경계는 규칙이 아니라 **야드·공장 배치와 크레인 능력에 따라 정해진다.** 같은 블록을 A 야드는 중조로, B 야드는 대조로 잡는다. `[G]`

`[?]` 확인 필요: 우리 야드의 소/중/대 구분 기준(중량? 피스 수? 형상?), 조립1~4과가 각각 어느 단계·어느 블록 타입을 담당하는가. AREA↔과 매핑(55A/61A=1과, 62A/63A=2과, 53A·C·E=3과, 3A·3A1=4과)은 있으나 **단계 담당 매핑은 아직 문서화 안 됨.**

## 4. 공종 — 배재 · 취부 · 오토캐리지 · 수동용접 · 사상 · 선주검사 · 곡직

정반 위 작업 순서는 원칙적으로 아래 순이고, 검사는 취부 후·용접 후 두 번 이상 끼어든다.

```
배재 → 취부 → (취부검사) → 용접 → 사상 → 곡직 → (정도검사 / 외관검사 / NDT) → 반출
        ↑___________________ R 판정 시 보수 후 재검 ___________|
```

### 4-1. 배재(配材)

부재를 도면상 위치로 **배치·공급**하는 작업. 정반에 그려진 기준선(마킹)에 맞춰 부재를 내려놓는다. 취부의 준비 공정이자, 자재 문제가 **처음 드러나는 지점**이다. `[G]`

| 항목 | 내용 |
|---|---|
| 앞 공정 | 가공품 입고 · 소팅 · 팔레트(자재 키트) 구성 |
| 관리 포인트 | 결품(미입고 부재), 오배재(다른 블록 부재 혼입), 부재 식별(피스 마킹 판독), 좌우 대칭 부재 혼동 |
| 실패 시 영향 | 결품 1장 때문에 취부 착수 불가 → 정반 점유만 발생하고 진도는 0 |
| 생산관리 신호 | **배재 단계 지연은 조립 지연의 선행지표.** 취부·용접이 밀리기 전에 여기서 먼저 보인다 |
| 등급 | `[G]` |

`[?]` 확인 필요: 배재 실적이 MES에 별도 이벤트로 남는가, 아니면 취부 착수로 뭉쳐 있는가. 남지 않으면 결품 선행경보를 만들 수 없다.

### 4-2. 취부(取付, Fit-up)

부재를 도면 위치·각도에 맞춰 맞대고 **가용접(tack weld)으로 고정**하는 작업. 조립 품질의 8할이 여기서 결정된다.

**관리 치수 (용접 전 반드시 확인)** `[E]`

| 항목 | 뜻 | 벗어나면 |
|---|---|---|
| 루트 갭 (Root Gap / 개선 간격) | 맞대기 이음의 틈 | 과대 → 용락·기공·과다입열 / 과소 → 용입부족 |
| 하이로 (Hi-Lo, 단차) | 두 판의 면 어긋남 | 응력집중, 검사 지적 |
| 개선각 (Bevel Angle) | 그루브 각도 | 용입 불량 |
| 직각도 / 수직도 | 론지·웹의 기울기 | 후행 부재 간섭, 정도 불량 |
| 대각선 치수 | 블록 뒤틀림 | 탑재 정도 불량 |

- **루트 갭은 WPS(용접절차서)에 규정된 값을 따르며, 승인 WPS 지정 갭의 2배를 넘지 않아야 한다는 기준이 일반적으로 적용된다.** `[E]`
- 가용접은 본용접까지 이음을 정위치에 붙잡아야 하므로, 가용접 자체의 길이·피치·품질도 관리 대상이다. `[E]`
- 취부 보조물: 스트롱백, 이렉션 피스(도그 피스), 턴버클, 쐐기, 서포트. 본용접 후 제거하고 제거부는 사상한다. 제거부 사상 누락이 검사 지적 단골. `[G]`

**정도불량률과의 관계**: 정도 불량은 대개 취부에서 생기고 곡직으로 덮는다. 정도불량률이 오르면 곡직 공수가 따라 오르므로, 두 지표는 같이 봐야 한다. `[G]`

### 4-3. 오토캐리지 (Auto Carriage, 자동용접 캐리지)

레일 또는 자석 주행으로 이음선을 따라가며 자동 용접하는 **주행형 자동용접기.** 조선·건설·중공업의 **대량 반복 용접**에 쓴다. `[E]` 용접법은 통상 FCAW(플럭스 코어드 아크 용접) — 와이어 내부에 플럭스가 채워진 FCW를 일정 속도로 공급하며 비드를 형성한다. `[E]`

| 항목 | 내용 |
|---|---|
| 적용 구간 | 직선 장거리 이음. 수평 필렛(론지-외판), 장직선 맞대기 |
| 장점 | 속도·입열·비드 균일 → **불량률 산포가 작다.** 작업자 기량 의존도 낮음 |
| 구조적 한계 | 시작·끝 부분(**비용접부**)은 자동화가 매우 어려워 수동 보정이 필요하다 `[E]` |
| 그 외 제약 | 곡선·협소부·장애물 구간 불가, 주행면 상태(스패터·요철)에 민감, 세팅 시간 발생 |
| 등급 | `[E]` |

**생산관리 함의**: 오토캐리지 적용률은 용접불량률을 낮추는 가장 직접적인 레버다. 다만 "자동 100%"는 원리적으로 불가능하다 — 시단·종단 비용접부는 남는다. 자동화율을 보고할 때 이 점을 빼면 첫 반문에서 무너진다.

`[?]` 확인 필요: 과별 오토캐리지 보유 대수, 적용 가능 이음 길이 비율, 자동/수동 용접 길이가 데이터로 분리되는가. **분리되지 않으면 "자동화율 → 불량률" 상관 분석 자체가 성립하지 않는다.**

### 4-4. 수동용접 (반자동 포함)

| 구분 | 용접법 | 주 용도 |
|---|---|---|
| 반자동 | FCAW / GMAW (현장 통칭 "CO2") | 조립 현장 주력. 곡선·입체·협소부 `[E]` |
| 수동 | SMAW (피복아크, "전기용접") | 보수, 가용접, 접근 곤란부 `[E]` |

- **불량률 산포의 주 원인**이 여기다. 동일 이음이라도 작업자 기량·자세·시야에 따라 결과가 갈린다. `[G]`
- 자세별 난이도: 아래보기(F) < 수평(H) < 수직(V) < 위보기(OH). 위보기는 공수와 불량률이 동시에 오른다. `[E]`
- 입체 대조립 블록은 내부 진입·밀폐구역 작업이 섞여 환기·조도·안전 조건까지 품질에 영향을 준다. `[G]`

`[?]` 확인 필요: 용접불량률 데이터에 자세·작업구분(자동/반자동/수동)·작업자 기량등급이 컬럼으로 있는가. 있으면 불량 요인 분해가 가능하고, 없으면 블록·이음 단위까지만 분석 가능.

### 4-5. 사상 (仕上, 그라인딩)

용접부와 표면을 정리하는 작업. 공수 비중이 크고 자동화가 가장 어렵다.

| 대상 | 내용 |
|---|---|
| 비드 정리 | 덧살 제거, 형상 정리, 언더컷·오버랩 수정 |
| 부착물 제거 | 스패터, 슬래그, 가용접 흔적, 이렉션 피스·스트롱백 제거부 |
| 가우징 후처리 | 백가우징(에어아크) 면 정리 후 재용접 준비 |
| 도장 전처리 | 표면 거칠기·이물 제거 — **도장 품질에 직결** |

- **검사 직전 관문**: 사상이 안 끝난 상태로 검사를 신청하면 외관에서 바로 지적된다. → **당일검사완료율을 떨어뜨리는 가장 흔한 원인이 "사상 미완 상태의 조기 신청"이다.** `[G]`
- 안전·보건: 진동(수완진동), 분진, 소음, 화기. 근골격계 부담 큼. `[G]`
- 등급: `[G]`

### 4-6. 선주검사 (선주 감독관 입회검사 · 선급 검사)

조립 단계에서 발생하는 입회검사. 우리 지표의 `용도결정 ∈ {A, R}`이 여기서 찍힌다.

**조립 단계에서 통상 받는 검사** `[G]` (구체 항목·단계는 호선·선주별로 다름 `[?]`)

| 검사 | 시점 | 보는 것 |
|---|---|---|
| 취부검사 (Fit-up) | 본용접 전 | 갭·하이로·개선·위치·가용접 |
| 외관검사 (VT) | 용접·사상 후 | 비드, 언더컷, 오버랩, 각장, 결함 |
| NDT 입회 | 용접 후 | MT(자분) / PT(침투) / UT(초음파) / RT(방사선) |
| 정도검사 | 곡직 후 | 주요 치수, 대각, 뒤틀림, 마진 |
| 내부검사 / 밀폐구역 검사 | 도장 전 | 탱크·구역 내부. **모든 구역에 대해 내부검사를 수행하는 것이 규칙상 요구** `[E]` |

**절차 흐름**

```
자체(사내) 선행검사 — QM/생산 자주검사
   → 검사신청 (MES 등록)
      → 입회 검사 (선주 감독관 / 선급 검사원)
         → 판정: A(합격) / R(불합격·재검사)
            → R이면 보수(가우징·재용접·사상) → 재검 신청 → 재검
```

**생산관리 관점의 핵심 4가지**

1. **재검은 원 검사와 별도 행으로 쌓인다.** `[C]` (2026-09-12 확인) 1차 R → 보수 → 재검 A 가 한 부위에 대해 **R 행 1개 + A 행 1개**로 남는다. 따라서 당일검사완료율의 분모는 "검사 부위 수"가 아니라 **"검사 시행 횟수"**다. 해석은 9-1절 참조. R 이력이 보존되는 것은 장점이고(사전경고 모델 학습 데이터로 직행), 대신 지표를 "부위 건수"로 읽으면 틀린다.
2. **신청 타이밍이 곧 지표다.** 너무 일찍 신청하면 R, 너무 늦으면 공정 지연. 당일검사완료율 = `A / (A+R) × 100`이므로 **R을 줄이는 것과 신청을 미루는 것은 지표상 구분되지 않는다** — 신청 건수 추이를 같이 보지 않으면 "R 줄이기"가 "신청 늦추기"로 변질될 수 있다. 이건 지표 설계의 알려진 구멍이므로 보고 시 신청 건수를 병기할 것.
3. **선주 성향 차이가 실재한다.** 같은 품질에도 선주·감독관별 지적 강도가 다르다. 선주별 R 분석을 별도로 두는 이유. `[G]`
4. **선급과 선주는 다른 주체다.** 선급(KR/DNV/LR/ABS 등)은 규칙 기준, 선주 감독관은 계약·사양 기준. 같은 부위를 다른 잣대로 본다. `[E]`

`[?]` 확인 필요: 검사 종류 코드 체계, R 사유 코드가 있는가(있으면 사전경고 모델 피처로 직행), **재검 행이 원 행을 가리키는 키(원 신청번호 참조 또는 검사 차수 컬럼)가 있는가** — 이게 없으면 1차 R률을 셀 수 없다.

### 4-7. 곡직(曲直, Line Heating)

가스 가열로 **용접 잔류응력을 완화하고 변형을 교정**하는 작업. `[E]`

**방법** `[E]`

| 방법 | 적용 |
|---|---|
| 선상가열 (연속형/단속형) | **현업에서 가장 널리 쓰임.** 선을 따라 가열 |
| 점가열 | 박판. **특히 두께 5mm 이하** |
| 십자형 가열 / 격자 가열 | 면 변형 교정 |

**관리 포인트** `[E]`

- 곡직 결과는 **작업자 기량에 따라 상이하며, 추가 공수와 비용이 발생한다.**
- **발주처(선주) 또는 강종에 따라 곡직 횟수에 제한을 두는 경우가 있다.** 따라서 초기 열변형을 최소화해 **곡직 횟수 자체를 줄이는 것이 정답**이고, 곡직 기량을 올리는 것은 차선이다.
- 고장력강(AH/DH/EH 계열)은 입열·예열·층간온도 관리가 엄격하다. 과열은 재질 열화. `[G]`

**생산관리 함의**: 곡직 공수는 "작업"이 아니라 **앞 공정 손실의 사후 비용**이다. 곡직 물량이 늘면 원인은 곡직 팀이 아니라 취부 정도·용접 순서·역변형 설계 쪽에 있다. 지표를 곡직 공수로만 보면 엉뚱한 곳을 압박하게 된다.

변형 저감의 정공법 순서: ① 역변형 부여 ② 용접 순서·대칭 용접 ③ 입열 저감(자동용접·적정 각장) ④ 구속 설계 ⑤ 그래도 남은 것만 곡직. `[G]`

## 5. O.H.C — Over Head Crane (천장크레인)

### 5-1. 구조와 정의

공장 건물 상부에 **평행한 두 레일**을 걸고 그 위를 이동하는 거더(브리지) + 트롤리(크래브) + 호이스트로 구성. 레일은 건물 기둥에 브래킷으로 고정된다. 공장·조선소에서 중량물의 설치·해체·이동에 쓴다. `[E]`

**갠트리/골리앗과의 구분** `[E]`

| | O.H.C (천장크레인) | 골리앗 / 갠트리 |
|---|---|---|
| 레일 위치 | 건물 상부 (기둥 브래킷) | 지상 레일 |
| 구조 | 브리지만 | 브리지 + 다리(레그) |
| 설치 장소 | 실내 조립공장 | 도크, PE장, 야외 정반 |
| 용도 | 공장 내 부재·블록 양중 | 대형 블록 탑재·이동 |
| 세미골리앗 | — | 한쪽은 지상 레일, 한쪽은 상부 레일 |

### 5-2. 왜 조립 공장의 병목 1순위인가

O.H.C 한 대(또는 한 베이의 몇 대)가 **여러 정반을 동시에 커버**한다. 그래서:

- 배재 요청, 반전, 반출, 지그 이동, 족장 자재 이동이 모두 같은 크레인을 두고 경쟁한다.
- 크레인 대기시간은 작업자 유휴로 잡히지 않고 **공정 리드타임에 조용히 숨는다.** 어느 공수표에도 "크레인 기다림"은 없다.
- 2대 합체 양중(반전, 초중량)이 걸리면 그 베이의 다른 모든 양중이 정지한다.

→ 조립 공장 개선에서 **"작업 속도"보다 "양중 대기"가 먼저 볼 대상**인 경우가 많다.

### 5-3. 용어

| 용어 | 뜻 | 등급 |
|---|---|---|
| SWL / 정격하중 | 안전 작업 하중 | `[E]` |
| 브리지 / 거더 | 레일 위를 종주하는 주 구조 | `[E]` |
| 트롤리 / 크래브 | 거더 위를 횡행하는 대차 | `[E]` |
| 호이스트 | 권상(들어올림) 장치 | `[E]` |
| 합체 양중 (2기 양중) | 크레인 2대를 동시 사용 | `[G]` |
| 러그 (Lug) | 인양용으로 블록에 용접하는 귀. 작업 후 제거·사상 | `[G]` |
| 샤클 / 와이어 / 슬링 | 인양 부속구 | `[E]` |
| 인양 지그 / 스프레더 | 하중 분산·자세 유지용 | `[G]` |

### 5-4. 안전 (조립부 중대재해 리스크 상위)

- 낙하·협착: 인양물 하부 출입금지 구역 설정, 신호수 배치, 유도로프.
- **러그 용접 품질이 인양 안전과 직결된다.** 러그 파단은 곧 낙하. 러그 용접은 "임시물"이라 관리에서 빠지기 쉬운데, 실제로는 검사 대상으로 다뤄야 하는 지점.
- 반전 작업은 하중 중심이 이동하는 순간이 가장 위험. 작업 순서·중심 계산이 사전에 확정되어야 함.
- `[?]` 확인 필요: 크레인 가동 이력(양중 시각·대기)이 시스템에 남는가. 남으면 정반 점유·대기 분석이 가능해지고, 이게 조립부 개선 과제의 가장 큰 미개척지다.

## 6. 정반(定盤) — 고정정반(핀지그)과 라인정반

### 6-1. 정반이란

블록을 올려놓고 조립하는 **작업 기준면.** 정반은 단순 바닥이 아니라 **치수의 기준(datum)** 이다. 정반의 평탄도·침하가 그대로 블록 정도로 전이된다. 정반은 소조립 조립, 블록 배치(레이아웃), 가용접, 최종 용접의 장소를 제공한다. `[E]`

### 6-2. 고정정반 = 핀지그 (Pin Jig)

**핀지그는 선체 곡면 외판을 구성하는 곡블록을 조립하기 위한 정반 라인이다. 구조적으로는 수직 스크류 잭(핀)의 배열로, 곡블록을 지지한다.** `[E]`

- 각 핀의 높이·각도를 조절해 크기·형상이 다른 블록의 **레벨과 각도를 맞추고, 블록 변형을 최소화하며 작업 효율을 높이는 것이 목적.** `[E]`
- **곡블록은 높이를 세팅한 핀지그 위에 올려지면 조립이 끝날 때까지 이동하지 않는다.** `[E]` → 그래서 "고정"정반이다.

| 항목 | 내용 |
|---|---|
| 대상 | 곡블록(선수·선미 외판, 빌지부 등), 입체 대조립 블록 |
| 점유 방식 | **셋업 → 완성까지 블록이 고정.** 공기 전체를 점유 |
| 셋업 데이터 | 외판 곡률(형상 데이터)에서 산출한 핀별 높이 — 별도 셋업 도면/데이터 필요 `[G]` |
| 능력 결정 요인 | **정반 수 × 공기.** 셋업 시간이 실질 능력을 깎는다 |
| 관리 리스크 | 핀 높이 셋업 오차, 핀 침하, 지지점 부족(국부 처짐), 셋업 도면 오류 → **전부 정도불량으로 귀결** |
| 안전 | 핀 사이 개구부 추락, 핀지그 작업대 승강, 블록 하부 진입 (위험도 평가 대상으로 다뤄지는 작업 단위) `[E]` |

### 6-3. 라인정반 (Line Platen)

평정반을 일렬로 배치해 **흐름 생산**하는 방식. 공정을 정반 단위 스테이션으로 쪼갠다. `[G]`

```
[정반1 배재] → [정반2 취부] → [정반3 용접] → [정반4 사상/검사] → 반출
```

| 항목 | 내용 |
|---|---|
| 대상 | 소조립, 평블록(중조), 패널 |
| 점유 방식 | 스테이션별 택트타임. 이동하며 가공 |
| 능력 결정 요인 | **가장 느린 스테이션 = 라인 능력.** 전형적 라인 밸런싱 문제 |
| 관리 리스크 | 한 스테이션 지연이 전체 정지, 스테이션 간 재공 적체, 이동 수단(대차·크레인) 대기 |
| 개선 레버 | 택트 균형, 병목 스테이션 인력·설비 증강, 자동화 투입 지점 선정 |

### 6-4. 두 방식의 대비 — 생산관리가 다르게 봐야 하는 이유

| 축 | 고정정반(핀지그) | 라인정반 |
|---|---|---|
| 생산 방식 | 정위치 고정형 (Fixed position) | 흐름 생산 (Flow) |

**이 표가 지표 왜곡의 근본 설명이다.** 고정정반 물량이 많은 과는 구조적으로 월말 몰림이 생기고, 라인정반 중심 과는 주간 추이가 매끄럽다. **두 과를 같은 주간 그래프로 비교하면 안 된다.** 근무일 보정만으로는 해결되지 않는다 — 인식 방식이 다르기 때문.

`[?]` 확인 필요: 조립4과(AREA 3A·3A1)의 정반 구성 — 고정정반 몇 면 / 라인정반 몇 스테이션, 정반별 담당 블록 타입. 이게 확정되면 과별 지표 비교의 정당한 기준선을 만들 수 있다.

## 9. 공종 → 지표 개선 레버 매핑

| 지표 | 목표 (`[?]` 재확인) | 주 발생 공종 | 실제 레버 | 흔한 오진 |
|---|---|---|---|---|
| 당일검사완료율 = A/(A+R)×100 | 98% | 선주검사 대응 · 사상 | 사내 선행검사 강화, 사상 완료 확인 후 신청, 선주별 지적 패턴 대비 | "검사원 성향 문제"로 종결 / 신청을 늦춰 지표만 올리기 |
| 용접불량률 = Σ불량길이/Σ검사길이×100 | 0.5 | 용접 (수동 비중) · 취부 | 오토캐리지 적용 구간 확대, 취부 갭·하이로 관리, 자세 개선(반전·회전 활용) | 용접사 개인 탓 / 기량교육만으로 접근 |
| 정도불량률 = Σ불합격/Σ전체×100 | 7.3 | 취부 · 정반 셋업 · 곡직 | 핀지그 셋업 정확도, 역변형 부여, 용접 순서 표준화, 수축 여유 재산정 | 곡직 팀 압박 (원인 공정이 아님) |

### 9-1. 당일검사완료율의 실제 계산 구조 — D1 확정 반영

재검이 **원 검사와 별도 행으로 쌓이므로** `[C]`, 한 부위가 여러 행을 만든다.

| 케이스 | 남는 행 | A행 | R행 | 그 부위의 기여 |
|---|---|---|---|---|
| 1차 합격 | A | 1 | 0 | 1/1 |
| 1차 R → 재검 A | R, A | 1 | 1 | 1/2 |
| 1차 R → 재검 R → 3차 A | R, R, A | 1 | 2 | 1/3 |

**월 누계로 보면 목표 98%는 이렇게 번역된다.**

부위 N개가 결국 모두 합격하고 그중 k개가 1차 R 후 1회 재검으로 통과한다고 두면
A행 = N · R행 = k → 지표 = `N / (N+k)`.

```
N/(N+k) ≥ 0.98  ⇔  k/N ≤ 0.0204
```

즉 **당일검사완료율 98% ≈ 1차 검사 불합격률 2.0% 이하.** 2회 이상 재검이 섞이면 R행이 더 늘어 기준이 더 빡세진다. 목표를 현장에 설명할 때 "98%"보다 **"100건 검사해서 1차에서 2건까지만 R"** 이 전달이 빠르다.

> 이 번역은 전제 2개에 걸려 있다 — ① 재검 행의 용도결정이 A로 찍히는가 ② 행이 1차인지 재검인지 데이터로 구분되는가. **②가 없으면 1차 R률 자체를 셀 수 없어 이 해석을 검증할 방법이 없다.** 검증로그 D7·D8 참조.

**일별과 월별이 다르게 움직인다.** 1차 R과 재검 A는 **다른 날**에 잡힌다. 같은 부위의 손실(R일)과 회복(재검일)이 분리되므로 **일별 지표 변동이 실제 품질 변동보다 크게 나타난다.** 일별 신호등이 bad로 떨어진 날 중 상당수는 그날 품질이 나빠진 게 아니라 **그날 R이 몰린 것**이고, 며칠 뒤 재검 A로 되올라온다.

→ **일별 신호등은 경보용, 판단은 월 누계로.** 이건 5장 데이터 원칙 7(주차 변동보다 월 집계 우선)이 조립 품질 지표에도 그대로 적용된다는 뜻이다. 원인은 다르다 — W.L은 완료 일괄 인식 때문이고, 검사 지표는 R과 재검의 날짜 분리 때문이다.

**신호등 판정** (`[?]` 배수 재확인 대상)
- 상향 지표(당일검사): `v ≥ 목표` good / `v ≥ 목표×0.97` warn / else bad
- 하향 지표(용접·정도): `v ≤ 목표` good / `v ≤ 목표×1.30` warn / else bad
- 색: good `#2c8a5f` / warn `#c89010` / bad `#b3402a`

**기성·조업도 계열**
```
기성금액     = 완료블럭 수 × 블럭당 금액
일당 기성    = 기성금액 ÷ 근무일수          ← 근무일 편차 제거 필수
공수 효율    = 기성금액 ÷ 공수
블럭당 난이도 = 난이도 점수합 ÷ 완료블럭 수   ← 일당 난이도보다 이걸 쓸 것
조업도       = t/man·day
```
조립 지식 관점에서 난이도 점수에 들어가야 할 항목 후보: 조립 단계(소/중/대), 곡·평 구분, 반전 횟수, 밀폐구역 유무, 위보기 용접 비율, 핀지그 셋업 여부. `[?]` 현재 산식 확인 필요.
