입반출 데이터를 지표에 쓰기 전에 아래 네 가지 정의를 확인해야 한다. 모두 사내 확인 대기 상태이며, 확인 전에는 이 값에 의존하는 지표를 확정 보고에 쓰지 않는다.

| 질문 | 왜 중요한가 | 상태 |
|---|---|---|
| 완료 판정 시점이 "용접완료"인가 "검사합격"인가 "반출"인가 | 기성금액과 조업도가 전부 달라진다 | 확인 대기 (질문 A1) |
| 반출일이 실적 입력일인가 실제 이동일인가 | 입력 지연이 진도율을 왜곡한다 | 확인 대기 (질문 B2) |
| 재입고(R 보수 후 재검, 재작업 복귀)가 별도 행으로 쌓이나 | 분모 중복 위험 | 확인 대기 |
| 적치장 경유가 반출로 잡히나 | 재공(WIP) 집계에 직결 | 확인 대기 (질문 B3) |
