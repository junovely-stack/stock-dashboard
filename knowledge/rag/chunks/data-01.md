| 공정 이벤트 | 남는 데이터(가정) | 연결 지표 | 상태 |
|---|---|---|---|
| 부재 입고 | 자재 입고 실적 | 결품 선행경보 | 확인 대기 |
| 배재 착수/완료 | (별도 이벤트 없을 가능성) | 지연 선행지표 | 확인 대기 |
| 취부 완료 | 공정 실적 | 진도율 | 확인 대기 |
| 검사신청 등록 | 검사신청 (구조) | 당일검사완료율 분모 | 운영 중 |
| 검사 판정 A/R | 용도결정 | 당일검사완료율 분자 | 운영 중 |
| 용접 검사 | 검사길이·불량길이 | 용접불량률 | 운영 중 |
| 정도 계측 | 합/불 판정 | 정도불량률 | 운영 중 |
| 곡직 실시 | (별도 기록 여부 불확실) | 손실 공수 | 확인 대기 |
| 블록 반출 | 반출일 | 기성·조업도 | 확인 대기 |
| 크레인 양중 | (기록 여부 불확실) | 대기 손실 | 확인 대기 |

요약: 지금 잡히는 것은 **검사·품질 계열**이고, 비어 있는 것은 **물류·점유·대기 계열**이다. 품질 지표는 대시보드로 돌고 있지만 "왜 늦었는가"에 답하는 데이터는 아직 없다. 다음 확장 방향은 새 품질 지표 추가보다 **입/반출·정반 점유 데이터 확보**가 효과가 크다. "확인 대기" 항목의 실제 유무는 추정하지 말 것.
