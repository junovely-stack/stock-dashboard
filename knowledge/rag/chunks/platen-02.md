핀지그는 **선체 곡면 외판을 구성하는 곡블록을 조립하기 위한 정반**이다. 구조적으로는 수직 스크류 잭(핀)의 배열로, 곡블록을 지지한다. 각 핀의 높이·각도를 조절해 크기·형상이 다른 블록의 **레벨과 각도를 맞추고, 블록 변형을 최소화하며 작업 효율을 높이는 것이 목적**이다.

**곡블록은 높이를 세팅한 핀지그 위에 올려지면 조립이 끝날 때까지 이동하지 않는다.** 그래서 "고정"정반이다.

| 항목 | 내용 |
|---|---|
| 대상 | 곡블록(선수·선미 외판, 빌지부 등), 입체 대조립 블록 |
| 점유 방식 | **셋업 → 완성까지 블록이 고정.** 공기 전체를 점유 |
| 셋업 데이터 | 외판 곡률(형상 데이터)에서 산출한 핀별 높이 — 별도 셋업 도면/데이터 필요 (업계통용) |
| 능력 결정 요인 | **정반 수 × 공기.** 셋업 시간이 실질 능력을 깎는다 |
| 관리 리스크 | 핀 높이 셋업 오차, 핀 침하, 지지점 부족(국부 처짐), 셋업 도면 오류 → **전부 정도불량으로 귀결** |
| 안전 | 핀 사이 개구부 추락, 핀지그 작업대 승강, 블록 하부 진입 — 위험도 평가 대상 작업 단위 |
