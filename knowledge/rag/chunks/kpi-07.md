```
기성금액     = 완료블럭 수 × 블럭당 금액
일당 기성    = 기성금액 ÷ 근무일수          ← 근무일 편차 제거 필수
공수 효율    = 기성금액 ÷ 공수
블럭당 난이도 = 난이도 점수합 ÷ 완료블럭 수   ← 일당 난이도보다 이걸 쓸 것
조업도       = t/man·day (EPC 처리량 / 기준 처리량)
연간 M/H    = (연간 발생 횟수 + 월 재작업 × 12) × 1회 소요 분 ÷ 60 × 인원
```

휴가·조업일수 차이가 있으면 근무일 기준으로 보정한 뒤 비교한다. 근무일수의 기준(달력? 과별 실제 조업일?)은 사내 확인 대기.

난이도 점수에 들어가야 할 항목 후보: 조립 단계(소/중/대), 곡·평 구분, 반전 횟수, 밀폐구역 유무, 위보기 용접 비율, 핀지그 셋업 여부. 현재 산식의 실제 구성 항목과 블럭당 금액의 출처, 완료 판정 시점은 모두 사내 확인 대기다.
