| 축 | 소조 → 대조 방향 |
|---|---|
| 피스 수 | 많음 → 적음 |
| 단위 중량 | 가벼움 → 무거움 |
| 입체도 | 평면 → 입체 (밀폐구역 발생) |
| 용접 자세 | 아래보기 위주 → 수직·위보기 증가 |
| 자동용접 적용률 | 높음 → 낮음 |
| 불량률 리스크 | 낮음 → 높음 (자세·접근성 때문) |
| 곡직 필요성 | 낮음 → 높음 (누적 변형) |
| 선주검사 강도 | 낮음 → 높음 (내부검사·밀폐구역 검사 발생) |
| 공기(리드타임) | 짧음 → 김 |

지표 설계에서의 함의: 소조와 대조를 같은 "블록 1개"로 세면 안 된다. 대조립 1블록과 소조립 1블록의 공수 차이는 수 배다. 그래서 **블럭당 난이도 = 난이도 점수합 ÷ 완료블럭 수**가 일당 난이도보다 유효하다. 단계·형상·반전 횟수·밀폐구역 유무가 난이도 점수에 반영되어야 하며, 현재 산식의 구성 항목은 사내 확인 대기다.
