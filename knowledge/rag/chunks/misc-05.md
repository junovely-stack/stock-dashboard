| 종류 | 뜻 | 보는 것 |
|---|---|---|
| VT | 육안 외관검사 | 비드, 언더컷, 오버랩, 각장 |
| MT (자분탐상) | 자력으로 자분을 모아 결함 표시 | 표면·근표면 결함 |
| PT (침투탐상) | 침투액·현상액 | 표면 결함 |
| UT (초음파탐상) | 초음파 반사 | 내부 결함 |
| RT (방사선투과) | 필름·디지털 투과상 | 내부 결함. **구역 통제·야간 작업 필요로 공정 간섭이 크다** |

조립 단계에서 선주·선급 입회 NDT가 발생하며, RT는 방사선 구역 통제 때문에 다른 작업을 멈추게 해 공정 간섭이 가장 크다.
