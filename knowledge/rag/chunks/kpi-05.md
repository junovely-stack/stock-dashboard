**98% / 0.5 / 7.3은 2026년도 기준값이다** (사내확정 2026-09-13). 목표가 해마다 다시 설정된다는 뜻이고, 세 가지가 따라온다.

| 함정 | 왜 틀리나 | 대응 |
|---|---|---|
| 연도 간 **달성률** 비교 | 목표선이 움직이므로 같은 실적도 연도마다 달성률이 달라진다 | 연도 비교는 **원지표(raw %)** 로. 달성률은 같은 해 안에서만 |
| 과거 데이터에 **신호등 소급 적용** | 2025년 실적에 2026년 목표를 씌우면 없던 bad가 생긴다 | 아카이브 스냅샷에 **그 해의 목표값을 함께 저장** |
| 연초 전환 구간 | 1월에 전년 12월 데이터를 보면 어느 목표를 쓸지 모호해진다 | **데이터 기준일의 연도**로 목표를 조회 (조회 시점이 아니라) |

코드 쪽 함의: 목표값을 하드코딩하면 연초에 여러 파일을 고쳐야 하고 반드시 하나를 빠뜨린다. **연도를 키로 갖는 설정 1곳**에 몰고, 데이터 기준일에서 연도를 뽑아 조회한다.

```python
TARGETS = {
    2026: {"당일검사완료율": 98.0, "용접불량률": 0.5, "정도불량률": 7.3},   # 사내확정
    2025: {"당일검사완료율": None, "용접불량률": None, "정도불량률": None},  # 확인 대기
}
```

전년(2025) 목표값과 연도별 목표 이력 관리처는 사내 확인 대기다. 채우기 전까지 전년 대비 비교 화면을 만들지 말 것. 신호등 배수(0.97/1.30)도 연 단위인지 고정인지는 확인 대기다.
