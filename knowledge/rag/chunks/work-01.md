정반 위 작업은 원칙적으로 아래 순서이고, 검사는 취부 후와 용접 후 두 번 이상 끼어든다. R(불합격) 판정이 나면 보수 후 재검을 받고 다음으로 넘어간다.

```
배재 → 취부 → (취부검사) → 용접 → 사상 → 곡직 → (정도검사 / 외관검사 / NDT) → 반출
        ↑___________________ R 판정 시 보수 후 재검 ___________|
```

공종별 역할: 배재는 부재 배치·공급, 취부는 부재를 맞대고 가용접으로 고정, 용접은 본용접, 사상은 비드·스패터 정리와 도장 전 표면 만들기, 곡직은 용접 열변형 교정, 검사는 선주·선급 입회 판정이다.
