| 수단 | 범위 | 특징 |
|---|---|---|
| O.H.C (천장크레인) | 공장 건물 내부 | 실내 양중 전담. 건물 상부 레일 주행 |
| 골리앗 / 갠트리 크레인 | 도크·PE장·야외 정반 | 지상 레일 + 다리 구조. 대형 중량물 |
| 트랜스포터 (T/P, MT) | 야드 전체 | 자주식 다축 대차. 유류·경로 비용이 실제 돈으로 잡힌다 |
| 대차 / 롤러 / 스키드 | 공장 내 라인 이동 | 라인정반의 흐름 이동 수단 (업계통용) |
| 턴오버 장치 / 포지셔너 | 블록 반전·경전 | 크레인 2대 합체 양중을 대체해 크레인 대기와 안전 리스크를 줄인다 |

대형 포지셔너·턴오버 장치·트랜스포터 같은 물류·세팅 설비는 생산능력 자체를 늘리지는 않지만 **크레인 대기시간과 안전 리스크를 줄여 공장 회전율을 올린다.** 조립 공장 설비 투자를 검토할 때 이 논리를 쓴다. 트랜스포터의 연간 유류·이동 횟수를 줄이는 블록 물류 최적화가 대형 조선소에서 실제 비용 절감 사례로 보고된 바 있다.
