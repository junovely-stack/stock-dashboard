1. **실적 입력 지연** — 작업은 화요일, 입력은 금요일. 주간 그래프가 무의미해진다. → 월 집계 우선 원칙의 근거.

2. **완료 인식 시점 불일치** — 용접완료 / 검사합격 / 반출 중 어느 것을 완료로 보는지 파일마다 다를 수 있다. → 기성·조업도가 파일 간에 안 맞는 전형적 원인. (완료 판정 시점은 사내 확인 대기)

3. **재작업 이력 구조 — 확정: 재검은 새 행으로 쌓인다** (사내확정 2026-09-12). R 이력은 보존되지만 **분모가 검사 시행 횟수 기준으로 늘어난다.** 지표를 부위 건수로 해석하면 틀리고, 재검 행을 걸러내려면 1차/재검 구분 키가 필요하다(유무 미확인). 원래 우려했던 "같은 행 갱신 → R 이력 소실"은 해당 없음.
