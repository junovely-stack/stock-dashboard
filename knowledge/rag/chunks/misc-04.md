|---|---|
| 개선 (Groove) | 용접을 위해 가공한 홈. 각도·형상이 용입을 결정 |
| 백비드 | 이면(반대쪽) 비드 (업계통용) |

| 기공 (Porosity) | 용접부 내부 공기구멍 |
| 슬래그 혼입 | 슬래그가 용접부에 갇힌 결함 |
| 융합불량 / 용입부족 | 모재와 붙지 않음 / 깊이 부족 |
