선박 건조는 강재 입고 → 전처리 → 가공 → 조립 → 도장 → PE → 탑재 → 진수 → 안벽 → 시운전 → 인도 순으로 흐른다. 조립은 그 한가운데다.

```
강재 입고
  └ 전처리 (쇼트블라스트 + 프라이머)
      └ 가공 (NC 절단 → 개선가공 → 벤딩/프레스/롤링)
          └ ■ 소조립  (부재 + 부재)                  ← 조립부
              └ ■ 중조립 (소조품 + 판 = 평블록)       ← 조립부
                  └ ■ 대조립 (입체블록 / 곡블록)      ← 조립부
                      └ 곡직 · 정도검사 · 선주검사     ← 조립부 (공정 내 삽입)
                          └ 도장 (블라스팅 + 도장)
                              └ PE (Pre-Erection, 지상 대조합)
                                  └ 탑재 (도크) → 진수 → 안벽 → 시운전 → 인도
```

조립부(조립1~4과)의 범위는 "가공품이 들어와서 도장 가능한 블록으로 나가기까지"다. 전처리는 강재 표면을 쇼트블라스트 후 프라이머 도장하는 공정, 가공은 NC 절단·개선가공·벤딩·프레스·롤링으로 부재를 만드는 공정이며 둘 다 조립보다 앞에 있다. PE(Pre-Erection)는 도크 탑재 전에 지상에서 블록을 미리 대조합하는 단계로 조립보다 뒤다.
