| 작업 | 주 위험 |
|---|---|
| 취부 | 협착(부재·지그), 중량물 넘어짐, 쐐기 타격 시 튐 |
| 그라인딩(사상) | 회전체 접촉, 비산물 눈 손상, 진동·분진, 화기 |
| 고소 (족장·핀지그 상부) | 추락, 개구부 |
| 양중 (O.H.C) | 낙하, 협착, 러그 파단 |
| 밀폐구역 (입체블록 내부) | 산소결핍, 유해가스, 화재, 탈출 지연 |
| 용접 | 아크광, 흄, 감전, 화재 |

외국인 인력(인도네시아·우즈베크·싱할라) 혼재 → 현장 배포물은 다국어 + 그림 중심. TBM 시각화 카드가 필요한 구조적 이유가 여기 있다.
