조립 단계에서 발생하는 입회검사다. 지표의 **용도결정 ∈ {A, R}** (A = 합격, R = 불합격·재검사)이 여기서 찍힌다.

조립 단계에서 통상 받는 검사 (구체 항목·단계는 호선·선주별로 다름 — 검사 종류 코드 체계는 사내 확인 대기):

| 검사 | 시점 | 보는 것 |
|---|---|---|
| 취부검사 (Fit-up) | 본용접 전 | 갭·하이로·개선·위치·가용접 |
| 외관검사 (VT) | 용접·사상 후 | 비드, 언더컷, 오버랩, 각장, 결함 |
| NDT 입회 | 용접 후 | MT(자분) / PT(침투) / UT(초음파) / RT(방사선) |
| 정도검사 | 곡직 후 | 주요 치수, 대각, 뒤틀림, 마진 |
| 내부검사 / 밀폐구역 검사 | 도장 전 | 탱크·구역 내부. 선급 규칙상 모든 구역에 대해 내부검사를 수행 |

절차 흐름:

```
자체(사내) 선행검사 — QM/생산 자주검사
   → 검사신청 (MES 등록)
      → 입회 검사 (선주 감독관 / 선급 검사원)
         → 판정: A(합격) / R(불합격·재검사)
            → R이면 보수(가우징·재용접·사상) → 재검 신청 → 재검
```

선급(KR/DNV/LR/ABS 등)은 규칙 기준으로, 선주 감독관은 계약·사양 기준으로 같은 부위를 다른 잣대로 본다. 두 주체는 다르다.
