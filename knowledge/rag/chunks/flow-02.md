조립 공정은 한 줄로 흐르는 라인이 아니다. 정반 위에서 배재 → 취부 → 용접 → 사상 → 곡직 → 검사가 겹쳐 돌아간다. 같은 정반에서 앞 블록이 사상 중이면 다음 블록 부재를 배재할 수 없다.

그래서 조립 공장의 실질 능력 상한은 작업 속도가 아니라 **정반 점유**다. 정반이 비어야 다음 블록이 들어오고, 정반이 막히면 인력이 남아 있어도 진도가 0이다. 이것이 조립 생산관리의 출발점이다.

생산관리가 실제로 들여다보는 것은 다음과 같다.

| 보는 것 | 왜 보는가 | 데이터 출처 |
|---|---|---|
| 정반 점유 / 회전 | 공장 능력의 실질 상한 | MES 정반 배정 테이블 유무는 확인 대기 |
| 블럭 입/반출일 | 공정 진도·기성 인식의 기준점 | 입고일·반출일 컬럼 유무는 확인 대기 |
| 검사 A/R | 당일검사완료율의 분자·분모 | 구조 검사신청 파일 (운영 중) |
| 용접 검사길이·불량길이 | 용접불량률 | 용접불량률 파일 (운영 중) |
| 정도 합/불 | 정도불량률 | 정도불량률 파일 + 물량정보 마스터 |
| 완료 블록 수 × 블럭당 금액 | 기성 | 완료 판정 시점 정의는 확인 대기 |
