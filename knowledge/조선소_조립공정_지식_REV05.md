## 1. 전체 흐름

### 조선 건조 전체 공정에서 조립이 끼어 있는 자리  `flow-01` · 등급 E

선박 건조는 강재 입고 → 전처리 → 가공 → 조립 → 도장 → PE → 탑재 → 진수 → 안벽 → 시운전 → 인도 순으로 흐른다. 조립은 그 한가운데다.

```
강재 입고
  └ 전처리 (쇼트블라스트 + 프라이머)
      └ 가공 (NC 절단 → 개선가공 → 벤딩/프레스/롤링)
          └ ■ 소조립  (부재 + 부재)                  ← 조립부
              └ ■ 중조립 (소조품 + 판 = 평블록)       ← 조립부
                  └ ■ 대조립 (입체블록 / 곡블록)      ← 조립부
                      └ 곡직 · 정도검사 · 선주검사     ← 조립부 (공정 내 삽입)
                          └ 도장 (블라스팅 + 도장)
                              └ PE (Pre-Erection, 지상 대조합)
                                  └ 탑재 (도크) → 진수 → 안벽 → 시운전 → 인도
```

조립부(조립1~4과)의 범위는 "가공품이 들어와서 도장 가능한 블록으로 나가기까지"다. 전처리는 강재 표면을 쇼트블라스트 후 프라이머 도장하는 공정, 가공은 NC 절단·개선가공·벤딩·프레스·롤링으로 부재를 만드는 공정이며 둘 다 조립보다 앞에 있다. PE(Pre-Erection)는 도크 탑재 전에 지상에서 블록을 미리 대조합하는 단계로 조립보다 뒤다.

*관련어: 건조 공정 흐름 · 선행 공정 · 후행 공정 · 가공 → 조립 → 도장 → 탑재*

### 조립 공정은 선형이 아니라 정반 위에서 겹쳐 돈다 — 정반 점유가 곧 능력  `flow-02` · 등급 G

조립 공정은 한 줄로 흐르는 라인이 아니다. 정반 위에서 배재 → 취부 → 용접 → 사상 → 곡직 → 검사가 겹쳐 돌아간다. 같은 정반에서 앞 블록이 사상 중이면 다음 블록 부재를 배재할 수 없다.

그래서 조립 공장의 실질 능력 상한은 작업 속도가 아니라 **정반 점유**다. 정반이 비어야 다음 블록이 들어오고, 정반이 막히면 인력이 남아 있어도 진도가 0이다. 이것이 조립 생산관리의 출발점이다.

생산관리가 실제로 들여다보는 것은 다음과 같다.

| 보는 것 | 왜 보는가 | 데이터 출처 |
|---|---|---|
| 정반 점유 / 회전 | 공장 능력의 실질 상한 | MES 정반 배정 테이블 유무는 확인 대기 |
| 블럭 입/반출일 | 공정 진도·기성 인식의 기준점 | 입고일·반출일 컬럼 유무는 확인 대기 |
| 검사 A/R | 당일검사완료율의 분자·분모 | 구조 검사신청 파일 (운영 중) |
| 용접 검사길이·불량길이 | 용접불량률 | 용접불량률 파일 (운영 중) |
| 정도 합/불 | 정도불량률 | 정도불량률 파일 + 물량정보 마스터 |
| 완료 블록 수 × 블럭당 금액 | 기성 | 완료 판정 시점 정의는 확인 대기 |

*관련어: 정반 점유 · 공장 능력 · 배재 취부 용접 사상 곡직 검사 순서*

## 2. 블럭 입/반출

### 블럭 입고와 반출 — 물리 이동이면서 정반 점유의 시작·종료 신호  `io-01` · 등급 G

**입고(투입)** 는 전 공정 산출물이 우리 공장 정반 또는 야드 적치장에 들어오는 이벤트다. 소조립은 가공 부재가, 중조립은 소조품과 판이, 대조립은 중조품(평블록)과 부재가 입고된다.

**반출(출고)** 는 자기 공정의 완료물을 후행 공정(중조·대조·도장·PE·적치장)으로 내보내는 이벤트다.

두 이벤트는 물리 이동이면서 동시에 **정반 점유의 시작·종료 신호**다. 생산관리에서 입반출 데이터가 중요한 이유는 이동 자체가 아니라 이 점유 구간 때문이다. 입고일과 반출일 사이가 그 블록이 정반을 차지한 시간이고, 정반 점유가 조립 공장 능력의 실질 상한이다.

*관련어: 입고 · 투입 · 반출 · 출고 · 블록 입출고*

### 블럭 운반 수단 — O.H.C, 골리앗, 트랜스포터, 대차, 턴오버 장치  `io-02` · 등급 E

| 수단 | 범위 | 특징 |
|---|---|---|
| O.H.C (천장크레인) | 공장 건물 내부 | 실내 양중 전담. 건물 상부 레일 주행 |
| 골리앗 / 갠트리 크레인 | 도크·PE장·야외 정반 | 지상 레일 + 다리 구조. 대형 중량물 |
| 트랜스포터 (T/P, MT) | 야드 전체 | 자주식 다축 대차. 유류·경로 비용이 실제 돈으로 잡힌다 |
| 대차 / 롤러 / 스키드 | 공장 내 라인 이동 | 라인정반의 흐름 이동 수단 (업계통용) |
| 턴오버 장치 / 포지셔너 | 블록 반전·경전 | 크레인 2대 합체 양중을 대체해 크레인 대기와 안전 리스크를 줄인다 |

대형 포지셔너·턴오버 장치·트랜스포터 같은 물류·세팅 설비는 생산능력 자체를 늘리지는 않지만 **크레인 대기시간과 안전 리스크를 줄여 공장 회전율을 올린다.** 조립 공장 설비 투자를 검토할 때 이 논리를 쓴다. 트랜스포터의 연간 유류·이동 횟수를 줄이는 블록 물류 최적화가 대형 조선소에서 실제 비용 절감 사례로 보고된 바 있다.

*관련어: 트랜스포터 · T/P · MT · 골리앗 크레인 · 갠트리 크레인 · 포지셔너 · 턴오버 장치 · 대차*

### 반전(턴오버) — 조립 특유의 함정, 크레인 점유와 난이도에 반영돼야 한다  `io-03` · 등급 G

평블록·곡블록은 한쪽 면을 용접한 뒤 뒤집어 반대면을 용접한다. 이 뒤집기가 반전(턴오버)이다. 반전에는 크레인 2대 동시 작업(합체 양중) 또는 턴오버 장치가 필요하고, 그 순간 그 베이의 다른 블록 양중이 전부 막힌다.

따라서 반전 횟수가 많은 블록은 크레인 점유가 큰 블록이고, **블록 난이도 점수에 반전 횟수가 반영되어야 한다.** 현재 난이도 점수 산식에 반전 횟수가 들어가는지는 사내 확인 대기 상태다.

반전 전에는 족장·서포트·지그를 정리해야 하므로 준비 공수가 별도로 붙는다. 반전 작업은 하중 중심이 이동하는 순간이 가장 위험해 작업 순서와 중심 계산이 사전에 확정되어야 한다.

*관련어: 턴오버 · 전도 · 블록 뒤집기 · 합체 양중 · 2기 양중*

### 반출 지연이 공정을 죽이는 경로 — 월말 몰림과 W.L 일괄 인식 착시  `io-04` · 등급 G

```
후행 공정 적체 (도장 대기 / PE 대기)
   → 반출 못 함
      → 정반 점유 지속
         → 다음 블록 입고 불가
            → 배재·취부 인력 유휴 또는 타 정반 과밀
               → 월말 몰림 → W.L(작업량) 일괄 인식 → 주간 생산성 착시
```

마지막 줄이 지표 왜곡의 실제 원인이다. 공기가 긴 대형 블록은 완료 시점에 W.L(Work Load, 작업량)이 한꺼번에 인식된다. 그래서 주간 그래프의 골과 봉우리는 대개 생산성 변화가 아니라 **인식 시점의 문제**다.

**주차 변동보다 월 집계를 우선하는 근거가 여기 있다.** 주간 수치로 과를 평가하면 완료 시점이 어느 주에 걸렸느냐로 결과가 갈린다.

*관련어: 후행 적체 · 도장 대기 · PE 대기 · 월말 몰림 · W.L 일괄 인식 · 주간 생산성 착시*

### 입반출 데이터에서 반드시 정의를 못 박아야 하는 4가지  `io-05` · 등급 ?

입반출 데이터를 지표에 쓰기 전에 아래 네 가지 정의를 확인해야 한다. 모두 사내 확인 대기 상태이며, 확인 전에는 이 값에 의존하는 지표를 확정 보고에 쓰지 않는다.

| 질문 | 왜 중요한가 | 상태 |
|---|---|---|
| 완료 판정 시점이 "용접완료"인가 "검사합격"인가 "반출"인가 | 기성금액과 조업도가 전부 달라진다 | 확인 대기 (질문 A1) |
| 반출일이 실적 입력일인가 실제 이동일인가 | 입력 지연이 진도율을 왜곡한다 | 확인 대기 (질문 B2) |
| 재입고(R 보수 후 재검, 재작업 복귀)가 별도 행으로 쌓이나 | 분모 중복 위험 | 확인 대기 |
| 적치장 경유가 반출로 잡히나 | 재공(WIP) 집계에 직결 | 확인 대기 (질문 B3) |

*관련어: 완료 판정 시점 · 반출일 정의 · 재입고 · 적치장 경유 · 재공 WIP*

## 3. 소조립 · 중조립 · 대조립

### 소조립·중조립·대조립 — 세 단계의 실체  `stage-01` · 등급 E

| | 소조립(小組立) | 중조립(中組立) | 대조립(大組立) |
|---|---|---|---|
| 투입물 | 가공 부재 (최소 2 Piece 이상) | 소조품 + 외판/내판 | 중조품(평블록) + 부재 + 소조품 |
| 산출물 | 부분 구조체 | 평블록 (Flat Block) | 입체블록 / 곡블록 |
| 대표 부재·블록 | 거더, 플로어, 웹, 론지, 브라켓, 스티프너 | 선체 중앙부 평블록, 외판·격벽 판 블록 | 선수, 선미, 엔진룸, 데크하우스, 곡블록 |
| 형상 | 2D 또는 얕은 3D | 평면 중심 | 입체 (내부 진입 필요) |
| 정반 | 라인정반 중심 | 라인정반 / 패널라인 | 고정정반(핀지그) 중심 |
| 자동화 | 높음 (로봇·전용기) | 중간 (패널라인 자동용접) | 낮음 (수동 비중 큼) |

규모 감각: 소조가 블록 한 곳의 귀퉁이를 만드는 것이라면, 중조·대조는 블록 하나 또는 블록들의 집합을 만드는 것이다. 소조립은 최소 2피스 이상의 부재를 취부·용접·사상해 거더·플로어·론지 같은 부분 구조체를 만들고, 중조립은 선체 중앙부 평블록을, 대조립은 선수·선미·엔진룸·데크처럼 대형화·입체화된 블록을 만든다.

*관련어: 소조 · 중조 · 대조 · sub-assembly · 평블록 · 곡블록 · 입체블록*

### 단계가 올라갈수록 무엇이 변하는가 — 소조 1블록과 대조 1블록은 같은 1이 아니다  `stage-02` · 등급 G

| 축 | 소조 → 대조 방향 |
|---|---|
| 피스 수 | 많음 → 적음 |
| 단위 중량 | 가벼움 → 무거움 |
| 입체도 | 평면 → 입체 (밀폐구역 발생) |
| 용접 자세 | 아래보기 위주 → 수직·위보기 증가 |
| 자동용접 적용률 | 높음 → 낮음 |
| 불량률 리스크 | 낮음 → 높음 (자세·접근성 때문) |
| 곡직 필요성 | 낮음 → 높음 (누적 변형) |
| 선주검사 강도 | 낮음 → 높음 (내부검사·밀폐구역 검사 발생) |
| 공기(리드타임) | 짧음 → 김 |

지표 설계에서의 함의: 소조와 대조를 같은 "블록 1개"로 세면 안 된다. 대조립 1블록과 소조립 1블록의 공수 차이는 수 배다. 그래서 **블럭당 난이도 = 난이도 점수합 ÷ 완료블럭 수**가 일당 난이도보다 유효하다. 단계·형상·반전 횟수·밀폐구역 유무가 난이도 점수에 반영되어야 하며, 현재 산식의 구성 항목은 사내 확인 대기다.

*관련어: 블럭당 난이도 · 단계별 공수 차이 · 밀폐구역 · 위보기 용접*

### 소/중/대 경계는 규칙이 아니라 야드 배치와 크레인 능력이 정한다  `stage-03` · 등급 ?

소/중/대 구분은 업계 공통 규칙이 아니다. **야드·공장 배치와 크레인 능력에 따라 정해진다.** 같은 블록을 A 야드는 중조로, B 야드는 대조로 잡는다.

우리 야드의 구분 기준(중량? 피스 수? 형상?)과 조립1~4과가 각각 어느 단계·어느 블록 타입을 담당하는지는 **사내 확인 대기**다. AREA와 과의 매핑(55A·61A=조립1과, 62A·63A=조립2과, 53A·53C·53E=조립3과, 3A·3A1=조립4과)은 확인됐지만, 단계 담당 매핑은 아직 문서화되지 않았다. 이 값을 묻는 질문에는 추정하지 말고 "확인 필요"로 답할 것.

*관련어: 단계 구분 기준 · 과별 담당 블록 · 조립1과 2과 3과 4과 담당*

## 4. 공종

### 정반 위 작업 순서 — 배재부터 반출까지, 검사는 두 번 이상 끼어든다  `work-01` · 등급 G

정반 위 작업은 원칙적으로 아래 순서이고, 검사는 취부 후와 용접 후 두 번 이상 끼어든다. R(불합격) 판정이 나면 보수 후 재검을 받고 다음으로 넘어간다.

```
배재 → 취부 → (취부검사) → 용접 → 사상 → 곡직 → (정도검사 / 외관검사 / NDT) → 반출
        ↑___________________ R 판정 시 보수 후 재검 ___________|
```

공종별 역할: 배재는 부재 배치·공급, 취부는 부재를 맞대고 가용접으로 고정, 용접은 본용접, 사상은 비드·스패터 정리와 도장 전 표면 만들기, 곡직은 용접 열변형 교정, 검사는 선주·선급 입회 판정이다.

*관련어: 공종 순서 · 조립 공정 순서 · R 판정 보수 재검*

### 배재(配材) — 부재를 정반 위 제자리에 놓는 일, 결품이 처음 드러나는 지점  `work-02` · 등급 G

배재는 부재를 도면상 위치로 배치·공급하는 작업이다. 정반에 그려진 기준선(마킹)에 맞춰 부재를 내려놓는다. 취부의 준비 공정이자 **자재 문제가 처음 드러나는 지점**이다.

| 항목 | 내용 |
|---|---|
| 앞 공정 | 가공품 입고 · 소팅 · 팔레트(자재 키트) 구성 |
| 관리 포인트 | 결품(미입고 부재), 오배재(다른 블록 부재 혼입), 부재 식별(피스 마킹 판독), 좌우 대칭 부재 혼동 |
| 실패 시 영향 | 결품 1장 때문에 취부 착수 불가 → 정반 점유만 발생하고 진도는 0 |
| 생산관리 신호 | **배재 단계 지연은 조립 지연의 선행지표.** 취부·용접이 밀리기 전에 여기서 먼저 보인다 |

배재 실적이 MES에 별도 이벤트로 남는지, 취부 착수에 뭉쳐 있는지는 사내 확인 대기다. 별도로 남지 않으면 결품 선행경보를 만들 수 없다.

*관련어: 배재 · 부재 배치 · 결품 · 오배재 · 자재 키트 · 팔레트*

### 취부(取付, Fit-up) — 부재를 맞대고 가용접으로 고정, 조립 품질의 8할이 여기서 결정된다  `work-03` · 등급 E

취부는 부재를 도면 위치·각도에 맞춰 맞대고 **가용접(tack weld)으로 고정**하는 작업이다. 조립 품질의 8할이 여기서 결정된다.

용접 전에 반드시 확인하는 관리 치수:

| 항목 | 뜻 | 벗어나면 |
|---|---|---|
| 루트 갭 (Root Gap, 개선 간격) | 맞대기 이음의 틈 | 과대 → 용락·기공·과다입열 / 과소 → 용입부족 |
| 하이로 (Hi-Lo, 단차) | 두 판의 면 어긋남 | 응력집중, 검사 지적 |
| 개선각 (Bevel Angle) | 그루브 각도 | 용입 불량 |
| 직각도 / 수직도 | 론지·웹의 기울기 | 후행 부재 간섭, 정도 불량 |
| 대각선 치수 | 블록 뒤틀림 | 탑재 정도 불량 |

루트 갭은 WPS(용접절차서)에 규정된 값을 따르며, **승인 WPS 지정 갭의 2배를 넘지 않아야 한다**는 기준이 일반적으로 적용된다. 용접 전 핏업 확인 항목에는 루트 갭, 하이로, 개선각, 랜드 두께, 가용접 품질, 백킹, 구속이 포함된다.

*관련어: 취부 · 핏업 · fit-up · 루트 갭 · 하이로 · 단차 · 개선각 · 대각선 치수*

### 취부의 가용접·임시 보조물, 그리고 정도불량률과의 관계  `work-04` · 등급 G

가용접은 본용접까지 이음을 정위치에 붙잡아야 하므로, 가용접 자체의 길이·피치·품질도 관리 대상이다.

취부 보조물로 스트롱백(판의 단차·벌어짐을 잡는 임시 보강재), 이렉션 피스(도그 피스 — 부재를 당기거나 밀어 위치를 잡는 임시 조각), 턴버클, 쐐기, 서포트를 쓴다. 본용접 후 제거하고 제거부는 사상한다. **제거부 사상 누락이 검사 지적의 단골**이다.

정도불량률(= Σ불합격 ÷ Σ전체 × 100)과의 관계: 정도 불량은 대개 취부에서 생기고 곡직으로 덮는다. 정도불량률이 오르면 곡직 공수가 따라 오르므로 **두 지표는 같이 봐야 한다.** 정도 불량의 원인 공정은 취부인데 발견 공정은 곡직 후 계측이라, 정도불량률만으로 책임을 배분하면 반발이 생긴다.

*관련어: 가용접 · 택 용접 · 스트롱백 · 이렉션 피스 · 도그 피스 · 쐐기 · 턴버클 · 서포트*

### 오토캐리지 — 주행형 자동용접기, 시단·종단은 자동화가 안 된다  `work-05` · 등급 E

오토캐리지는 레일 또는 자석 주행으로 이음선을 따라가며 자동 용접하는 **주행형 자동용접기**다. 조선·건설·중공업의 대량 반복 용접에 쓴다. 용접법은 통상 FCAW(플럭스 코어드 아크 용접) — 와이어 내부에 플럭스가 채워진 FCW를 일정 속도로 공급하며 비드를 형성한다.

| 항목 | 내용 |
|---|---|
| 적용 구간 | 직선 장거리 이음. 수평 필렛(론지-외판), 장직선 맞대기 |
| 장점 | 속도·입열·비드 균일 → **불량률 산포가 작다.** 작업자 기량 의존도 낮음 |
| 구조적 한계 | 시작·끝 부분(**비용접부**)은 자동화가 매우 어려워 수동 보정이 필요하다 |
| 그 외 제약 | 곡선·협소부·장애물 구간 불가, 주행면 상태(스패터·요철)에 민감, 세팅 시간 발생 |

생산관리 함의: 오토캐리지 적용률은 용접불량률을 낮추는 가장 직접적인 레버다. 다만 "자동 100%"는 원리적으로 불가능하다 — 시단·종단 비용접부는 남는다. 자동화율을 보고할 때 이 점을 빼면 첫 반문에서 무너진다.

과별 오토캐리지 보유 대수, 적용 가능 이음 비율, 자동/수동 용접 길이가 데이터로 분리되는지는 사내 확인 대기다. **분리되지 않으면 "자동화율 → 불량률" 상관 분석 자체가 성립하지 않는다.**

*관련어: 오토캐리지 · 자동용접 캐리지 · auto carriage · 비용접부 · FCAW · 자동화율*

### 수동용접과 반자동(CO2) 용접 — 불량률 산포의 주 원인, 자세가 난이도를 가른다  `work-06` · 등급 E

| 구분 | 용접법 | 주 용도 |
|---|---|---|
| 반자동 | FCAW / GMAW (현장 통칭 "CO2") | 조립 현장 주력. 곡선·입체·협소부 |
| 수동 | SMAW (피복아크, "전기용접") | 보수, 가용접, 접근 곤란부 |

**불량률 산포의 주 원인**이 여기다. 동일 이음이라도 작업자 기량·자세·시야에 따라 결과가 갈린다.

자세별 난이도: 아래보기(F) < 수평(H) < 수직(V) < 위보기(OH). **위보기는 공수와 불량률이 동시에 오른다.** 입체 대조립 블록은 내부 진입·밀폐구역 작업이 섞여 환기·조도·안전 조건까지 품질에 영향을 준다.

용접불량률 데이터에 자세·작업구분(자동/반자동/수동)·작업자 기량등급이 컬럼으로 있는지는 사내 확인 대기다. 있으면 불량 요인 분해가 가능하고, 없으면 블록·이음 단위까지만 분석할 수 있다.

*관련어: 수동용접 · 반자동 용접 · CO2 용접 · FCAW · GMAW · SMAW · 전기용접 · 용접 자세 · 위보기 · 아래보기*

### 사상(仕上, 그라인딩) — 검사 직전 관문, 공수 비중이 크고 자동화가 가장 어렵다  `work-07` · 등급 G

사상은 용접부와 표면을 정리하는 작업이다.

| 대상 | 내용 |
|---|---|
| 비드 정리 | 덧살 제거, 형상 정리, 언더컷·오버랩 수정 |
| 부착물 제거 | 스패터, 슬래그, 가용접 흔적, 이렉션 피스·스트롱백 제거부 |
| 가우징 후처리 | 백가우징(에어아크) 면 정리 후 재용접 준비 |
| 도장 전처리 | 표면 거칠기·이물 제거 — **도장 품질에 직결** |

**검사 직전 관문**이다. 사상이 안 끝난 상태로 검사를 신청하면 외관에서 바로 지적된다. **당일검사완료율을 떨어뜨리는 가장 흔한 원인이 "사상 미완 상태의 조기 신청"** 이라는 것이 실무 경험상의 가설이며, R 사유 코드 데이터가 확인되면 검증할 수 있다.

안전·보건: 진동(수완진동), 분진, 소음, 화기. 근골격계 부담이 크다.

*관련어: 사상 · 그라인딩 · 시아게 · 비드 정리 · 스패터 제거 · 도장 전처리*

### 선주검사·선급검사 — 조립 단계에서 받는 검사 종류와 신청→판정 절차  `work-08` · 등급 G

조립 단계에서 발생하는 입회검사다. 지표의 **용도결정 ∈ {A, R}** (A = 합격, R = 불합격·재검사)이 여기서 찍힌다.

조립 단계에서 통상 받는 검사 (구체 항목·단계는 호선·선주별로 다름 — 검사 종류 코드 체계는 사내 확인 대기):

| 검사 | 시점 | 보는 것 |
|---|---|---|
| 취부검사 (Fit-up) | 본용접 전 | 갭·하이로·개선·위치·가용접 |
| 외관검사 (VT) | 용접·사상 후 | 비드, 언더컷, 오버랩, 각장, 결함 |
| NDT 입회 | 용접 후 | MT(자분) / PT(침투) / UT(초음파) / RT(방사선) |
| 정도검사 | 곡직 후 | 주요 치수, 대각, 뒤틀림, 마진 |
| 내부검사 / 밀폐구역 검사 | 도장 전 | 탱크·구역 내부. 선급 규칙상 모든 구역에 대해 내부검사를 수행 |

절차 흐름:

```
자체(사내) 선행검사 — QM/생산 자주검사
   → 검사신청 (MES 등록)
      → 입회 검사 (선주 감독관 / 선급 검사원)
         → 판정: A(합격) / R(불합격·재검사)
            → R이면 보수(가우징·재용접·사상) → 재검 신청 → 재검
```

선급(KR/DNV/LR/ABS 등)은 규칙 기준으로, 선주 감독관은 계약·사양 기준으로 같은 부위를 다른 잣대로 본다. 두 주체는 다르다.

*관련어: 선주검사 · 입회검사 · 선급검사 · 검사신청 · 용도결정 · A/R · 취부검사 · 내부검사 · 밀폐구역 검사*

### 선주검사에서 생산관리가 봐야 할 4가지 — 재검은 별도 행, 신청 타이밍, 선주 성향, 선급≠선주  `work-09` · 등급 C

1. **재검은 원 검사와 별도 행으로 쌓인다.** (사내확정, 2026-09-12) 1차 R → 보수 → 재검 A 가 한 부위에 대해 R 행 1개 + A 행 1개로 남는다. 따라서 당일검사완료율 = A/(A+R)×100의 분모는 "검사 부위 수"가 아니라 **"검사 시행 횟수"** 다. R 이력이 보존되는 것은 장점이고(사전경고 모델 학습 데이터로 직행), 대신 지표를 "부위 건수"로 읽으면 틀린다.

2. **신청 타이밍이 곧 지표다.** 너무 일찍 신청하면 R, 너무 늦으면 공정 지연. A/(A+R) 공식으로는 **R을 줄이는 것과 신청을 미루는 것이 구분되지 않는다** — 신청 건수 추이를 같이 보지 않으면 "R 줄이기"가 "신청 늦추기"로 변질될 수 있다. 지표 설계의 알려진 구멍이므로 보고 시 신청 건수를 병기할 것.

3. **선주 성향 차이가 실재한다.** 같은 품질에도 선주·감독관별 지적 강도가 다르다. 선주별 R 분석을 별도로 두는 이유다. (업계통용)

4. **선급과 선주는 다른 주체다.** 선급은 규칙 기준, 선주 감독관은 계약·사양 기준.

재검 행이 원 행을 가리키는 키(원 신청번호 참조 또는 검사 차수 컬럼)가 있는지, R 사유 코드가 있는지는 사내 확인 대기다. 구분 키가 없으면 1차 R률을 셀 수 없다.

*관련어: 재검 · 재검사 행 · 검사 신청 타이밍 · 선주 성향 · 선주별 R 분석 · 신청 지연*

### 곡직(曲直, Line Heating) — 열변형 교정, 곡직 물량은 작업이 아니라 앞 공정 손실의 비용  `work-10` · 등급 E

곡직은 가스 가열로 **용접 잔류응력을 완화하고 변형을 교정**하는 작업이다.

| 방법 | 적용 |
|---|---|
| 선상가열 (연속형/단속형) | **현업에서 가장 널리 쓰임.** 선을 따라 가열 |
| 점가열 | 박판. **특히 두께 5mm 이하** |
| 십자형 가열 / 격자 가열 | 면 변형 교정 |

관리 포인트: 곡직 결과는 **작업자 기량에 따라 상이하며 추가 공수와 비용이 발생한다.** **발주처(선주) 또는 강종에 따라 곡직 횟수에 제한을 두는 경우가 있다.** 따라서 초기 열변형을 최소화해 곡직 횟수 자체를 줄이는 것이 정답이고, 곡직 기량을 올리는 것은 차선이다. 고장력강(AH/DH/EH 계열)은 입열·예열·층간온도 관리가 엄격하다.

생산관리 함의: **곡직 공수는 "작업"이 아니라 앞 공정 손실의 사후 비용**이다. 곡직 물량이 늘면 원인은 곡직 팀이 아니라 취부 정도·용접 순서·역변형 설계 쪽에 있다. 지표를 곡직 공수로만 보면 엉뚱한 곳을 압박하게 된다.

변형 저감의 정공법 순서: ① 역변형 부여 ② 용접 순서·대칭 용접 ③ 입열 저감(자동용접·적정 각장) ④ 구속 설계 ⑤ 그래도 남은 것만 곡직.

*관련어: 곡직 · 선상가열 · line heating · 점가열 · 격자가열 · 역변형 · 잔류응력 · 변형 교정*

## 5. O.H.C

### O.H.C(천장크레인) — 구조·정의, 골리앗/갠트리와의 구분  `ohc-01` · 등급 E

O.H.C(Over Head Crane, 천장크레인)는 공장 건물 상부에 **평행한 두 레일**을 걸고 그 위를 이동하는 거더(브리지) + 트롤리(크래브) + 호이스트로 구성된다. 레일은 건물 기둥에 브래킷으로 고정된다. 공장·조선소에서 중량물의 설치·해체·이동에 쓴다.

| | O.H.C (천장크레인) | 골리앗 / 갠트리 |
|---|---|---|
| 레일 위치 | 건물 상부 (기둥 브래킷) | 지상 레일 |
| 구조 | 브리지만 | 브리지 + 다리(레그) |
| 설치 장소 | 실내 조립공장 | 도크, PE장, 야외 정반 |
| 용도 | 공장 내 부재·블록 양중 | 대형 블록 탑재·이동 |
| 세미골리앗 | — | 한쪽은 지상 레일, 한쪽은 상부 레일 |

영국식으로 골리앗(goliath), 미국식으로 갠트리(gantry)라 부르며 같은 구조다. 조선소에서 천장크레인은 실내 조립 베이에, 갠트리·골리앗은 블록 조립장과 도크에 쓴다.

*관련어: O.H.C · OHC · 천장크레인 · Over Head Crane · 오버헤드 크레인 · 골리앗 크레인 · 갠트리 크레인 · 세미골리앗*

### O.H.C가 조립 공장의 병목 1순위인 이유 — 크레인 대기는 어느 공수표에도 없다  `ohc-02` · 등급 G

O.H.C 한 대(또는 한 베이의 몇 대)가 **여러 정반을 동시에 커버**한다. 그래서:

- 배재 요청, 반전, 반출, 지그 이동, 족장 자재 이동이 모두 같은 크레인을 두고 경쟁한다.
- 크레인 대기시간은 작업자 유휴로 잡히지 않고 **공정 리드타임에 조용히 숨는다.** 어느 공수표에도 "크레인 기다림"은 없다.
- 2대 합체 양중(반전, 초중량)이 걸리면 그 베이의 다른 모든 양중이 정지한다.

→ 조립 공장 개선에서 **"작업 속도"보다 "양중 대기"가 먼저 볼 대상**인 경우가 많다.

크레인 가동 이력(양중 시각·대기)이 시스템에 남는지는 사내 확인 대기다. 남으면 정반 점유·대기 분석이 가능해지고, 이것이 조립부 개선 과제의 가장 큰 미개척지다.

*관련어: 크레인 대기 · 양중 대기 · 병목 · 합체 양중 · 베이*

### 크레인 양중 용어 — SWL, 거더, 트롤리, 호이스트, 러그, 샤클, 스프레더, 신호수  `ohc-03` · 등급 E

| 용어 | 뜻 |
|---|---|
| SWL / 정격하중 | 안전 작업 하중 |
| 브리지 / 거더 | 레일 위를 종주하는 주 구조 |
| 트롤리 / 크래브 | 거더 위를 횡행하는 대차 |
| 호이스트 | 권상(들어올림) 장치 |
| 합체 양중 (2기 양중) | 크레인 2대를 동시 사용 (업계통용) |
| 러그 (Lug) | 인양용으로 블록에 용접하는 귀. 작업 후 제거·사상 (업계통용) |
| 샤클 / 와이어 / 슬링 | 인양 부속구 |
| 인양 지그 / 스프레더 | 하중 분산·자세 유지용 (업계통용) |
| 신호수 | 크레인 유도자. 배치가 법적 요구 (업계통용) |

*관련어: SWL · 정격하중 · 거더 · 브리지 · 트롤리 · 크래브 · 호이스트 · 러그 · 샤클 · 슬링 · 스프레더 · 신호수*

### 양중 안전 — 낙하·협착, 러그 용접 품질, 반전 중 하중 중심 이동  `ohc-04` · 등급 G

양중은 조립부 중대재해 리스크 상위다.

- 낙하·협착: 인양물 하부 출입금지 구역 설정, 신호수 배치, 유도로프.
- **러그 용접 품질이 인양 안전과 직결된다.** 러그 파단은 곧 낙하다. 러그 용접은 "임시물"이라 관리에서 빠지기 쉬운데, 실제로는 검사 대상으로 다뤄야 하는 지점이다.
- 반전 작업은 하중 중심이 이동하는 순간이 가장 위험하다. 작업 순서·중심 계산이 사전에 확정되어야 한다.
- 2대 합체 양중은 두 크레인의 속도 차가 하중 쏠림을 만든다. 신호 체계를 단일화할 것.

*관련어: 양중 안전 · 러그 파단 · 인양물 하부 출입금지 · 낙하 · 협착*

## 6. 정반

### 정반(定盤)이란 — 작업 바닥이 아니라 치수의 기준(datum)  `platen-01` · 등급 E

정반은 블록을 올려놓고 조립하는 **작업 기준면**이다. 단순 바닥이 아니라 **치수의 기준(datum)** 이다. 정반의 평탄도·침하가 그대로 블록 정도(精度)로 전이된다.

정반은 소조립 조립, 블록 배치(레이아웃), 가용접, 최종 용접의 장소를 제공한다. 정반은 크게 두 방식으로 운영된다 — 블록을 셋업 후 완성까지 고정하는 **고정정반(핀지그)** 과, 평정반을 일렬로 놓고 스테이션 단위로 흐르게 하는 **라인정반**.

*관련어: 정반 · platen · 작업 기준면 · datum · 정반 평탄도*

### 고정정반 = 핀지그(Pin Jig) — 곡블록을 셋업 후 완성까지 고정, 셋업 시간이 능력을 깎는다  `platen-02` · 등급 E

핀지그는 **선체 곡면 외판을 구성하는 곡블록을 조립하기 위한 정반**이다. 구조적으로는 수직 스크류 잭(핀)의 배열로, 곡블록을 지지한다. 각 핀의 높이·각도를 조절해 크기·형상이 다른 블록의 **레벨과 각도를 맞추고, 블록 변형을 최소화하며 작업 효율을 높이는 것이 목적**이다.

**곡블록은 높이를 세팅한 핀지그 위에 올려지면 조립이 끝날 때까지 이동하지 않는다.** 그래서 "고정"정반이다.

| 항목 | 내용 |
|---|---|
| 대상 | 곡블록(선수·선미 외판, 빌지부 등), 입체 대조립 블록 |
| 점유 방식 | **셋업 → 완성까지 블록이 고정.** 공기 전체를 점유 |
| 셋업 데이터 | 외판 곡률(형상 데이터)에서 산출한 핀별 높이 — 별도 셋업 도면/데이터 필요 (업계통용) |
| 능력 결정 요인 | **정반 수 × 공기.** 셋업 시간이 실질 능력을 깎는다 |
| 관리 리스크 | 핀 높이 셋업 오차, 핀 침하, 지지점 부족(국부 처짐), 셋업 도면 오류 → **전부 정도불량으로 귀결** |
| 안전 | 핀 사이 개구부 추락, 핀지그 작업대 승강, 블록 하부 진입 — 위험도 평가 대상 작업 단위 |

*관련어: 핀지그 · pin jig · 고정정반 · 스크류 잭 · 핀 높이 셋업 · 곡블록 정반*

### 라인정반 — 평정반을 일렬로 놓고 스테이션 단위로 흐르는 생산, 가장 느린 스테이션이 능력  `platen-03` · 등급 G

라인정반은 평정반을 일렬로 배치해 **흐름 생산**하는 방식이다. 공정을 정반 단위 스테이션으로 쪼갠다.

```
[정반1 배재] → [정반2 취부] → [정반3 용접] → [정반4 사상/검사] → 반출
```

| 항목 | 내용 |
|---|---|
| 대상 | 소조립, 평블록(중조), 패널 |
| 점유 방식 | 스테이션별 택트타임. 이동하며 가공 |
| 능력 결정 요인 | **가장 느린 스테이션 = 라인 능력.** 전형적 라인 밸런싱 문제 |
| 관리 리스크 | 한 스테이션 지연이 전체 정지, 스테이션 간 재공 적체, 이동 수단(대차·크레인) 대기 |
| 개선 레버 | 택트 균형, 병목 스테이션 인력·설비 증강, 자동화 투입 지점 선정 |

패널라인은 평판에 론지를 자동 용접하는 전용 라인으로 중조립의 자동화 구간이다.

*관련어: 라인정반 · line platen · 패널라인 · 택트타임 · 스테이션 · 흐름 생산 · 라인 밸런싱*

### 고정정반 과와 라인정반 과를 같은 주간 그래프로 비교하면 안 되는 이유  `platen-04` · 등급 G

| 축 | 고정정반(핀지그) | 라인정반 |
|---|---|---|
| 생산 방식 | 정위치 고정형 (Fixed position) | 흐름 생산 (Flow) |
| 능력 산정 | 정반 수 × 회전율 | 택트타임 × 가동시간 |
| 병목 | 정반 점유 자체 | 최저속 스테이션 |
| 진도 관리 단위 | 블록 1개 (장기) | 스테이션 통과 (단기) |
| 지연 전파 | 그 정반만 정지 | 라인 전체 정지 |
| 실적 인식 | 완료 시 일괄 → **W.L(작업량) 몰림 발생** | 통과 시 분산 |
| 핵심 KPI | 정반 회전율, 셋업 시간 | 택트 준수율, 스테이션 대기 |

**이 표가 지표 왜곡의 근본 설명이다.** 고정정반 물량이 많은 과는 구조적으로 월말 몰림이 생기고, 라인정반 중심 과는 주간 추이가 매끄럽다. **두 과를 같은 주간 그래프로 비교하면 안 된다.** 근무일 보정만으로는 해결되지 않는다 — 인식 방식 자체가 다르기 때문이다.

정반 회전율 = 기간 내 완료 블록 수 ÷ 정반 수. 고정정반 공장의 핵심 능력 지표다.

조립4과(AREA 3A·3A1)의 정반 구성 — 고정정반 몇 면 / 라인정반 몇 스테이션, 정반별 담당 블록 타입 — 은 사내 확인 대기다. 이것이 확정되어야 과별 지표 비교의 정당한 기준선을 만들 수 있다.

*관련어: 과별 비교 · 정반 회전율 · 택트 준수율 · 실적 인식 방식 · 지표 왜곡*

## 7. 주변 지식

### 정도관리(Accuracy Control) — 계측·기준·여유, 원인 공정과 발견 공정이 다르다  `misc-01` · 등급 G

정도관리는 블록의 치수·형상을 관리하는 체계다. 정도불량률 = Σ불합격 ÷ Σ전체 × 100 (2026년도 목표 7.3, 사내확정).

| 항목 | 내용 |
|---|---|
| 계측 수단 | 줄자·수평기, 토탈스테이션, 3D 스캐너 |
| 기준 | 마킹된 기준선(센터라인·버트라인·워터라인)과 도면 치수 |
| 관리 항목 | 주요 치수, 대각선(뒤틀림), 직각도, 평탄도, 마진(여유) 잔량 |
| 여유(마진) | 절단 여유 + **수축 여유** — 용접 수축을 예상해 미리 크게 잡는 값. 후공정 탑재 정도 확보용 |
| 시점 | 취부 후 · 용접 후 · 곡직 후 (최종) |

정도관리의 정치적 성격: 정도 불량은 **원인 공정과 발견 공정이 다르다.** 취부에서 생긴 문제가 곡직 후 계측에서 발견된다. 그래서 정도불량률만으로 책임을 배분하면 반발이 생긴다. 원인 공정 코드가 같이 있어야 하며, 그 유무는 사내 확인 대기다.

*관련어: 정도관리 · accuracy control · 정도불량률 · 토탈스테이션 · 3D 스캐너 · 수축 여유 · 마진 · 대각선 치수*

### 마킹과 기준선 — 센터라인, 버트라인, 워터라인, 부재 위치선, 검사선  `misc-02` · 등급 E

마킹은 정반·부재에 기준선·위치선·절단선·검사선을 표시하는 작업이다. 배재와 취부가 이 선을 기준으로 이루어진다.

| 용어 | 뜻 |
|---|---|
| 센터라인 (C.L) | 선체 폭 방향 중심선 |
| 버트라인 (B.L) | 종방향 기준선 |
| 워터라인 (W.L) | 수선. 흘수 기준선 |
| 부재 위치선 | 론지·거더가 앉을 자리 |
| 검사선 | 검사 기준용 마킹 |

설계·정도 문서의 W.L(Water Line, 수선)은 생산관리 지표의 W.L(Work Load, 작업량)과 약어가 같다. 어느 쪽인지는 문맥으로 구분해야 한다.

*관련어: 마킹 · 먹매김 · 센터라인 · C.L · 버트라인 · B.L · 워터라인 · 수선 · 기준선*

### W.L 약어 충돌 — 작업량(Work Load)과 수선(Water Line)은 같은 글자다  `misc-03` · 등급 ?

`W.L`은 두 가지 뜻으로 쓰인다.

- **생산관리·지표 문서의 W.L = 작업량(Work Load).** 공수 환산 작업량. "W.L 일괄 인식", "주간 W.L" 같은 표현이 이쪽이다.
- **설계·정도 문서의 W.L = 수선(Water Line).** 흘수 기준선. 센터라인·버트라인과 함께 쓰이면 이쪽이다.

AI 에이전트가 이 지식을 쓸 때 반드시 문맥으로 구분해야 한다. 지표·생산성·공수 맥락이면 작업량, 마킹·기준선·정도 맥락이면 수선이다.

사내 문서에서 W.L을 어느 뜻으로 주로 쓰는지, 구분 표기 관례가 있는지는 사내 확인 대기다. 확정 전에는 애매한 질문에 두 뜻을 모두 제시할 것.

*관련어: W.L · WL · Work Load · Water Line · 작업량 · 수선 · 약어 충돌*

### 조립 데이터가 조용히 틀리는 3가지 경로 — 입력 지연, 완료 시점 불일치, 재작업 이력 구조  `data-02` · 등급 C

1. **실적 입력 지연** — 작업은 화요일, 입력은 금요일. 주간 그래프가 무의미해진다. → 월 집계 우선 원칙의 근거.

2. **완료 인식 시점 불일치** — 용접완료 / 검사합격 / 반출 중 어느 것을 완료로 보는지 파일마다 다를 수 있다. → 기성·조업도가 파일 간에 안 맞는 전형적 원인. (완료 판정 시점은 사내 확인 대기)

3. **재작업 이력 구조 — 확정: 재검은 새 행으로 쌓인다** (사내확정 2026-09-12). R 이력은 보존되지만 **분모가 검사 시행 횟수 기준으로 늘어난다.** 지표를 부위 건수로 해석하면 틀리고, 재검 행을 걸러내려면 1차/재검 구분 키가 필요하다(유무 미확인). 원래 우려했던 "같은 행 갱신 → R 이력 소실"은 해당 없음.

*관련어: 실적 입력 지연 · 완료 인식 시점 · 재작업 이력 · 분모 중복 · 조용히 틀리는 데이터*

### 3대 품질 지표 — 정의·2026년 목표·주 발생 공종·실제 레버·흔한 오진  `kpi-01` · 등급 C

목표값 98 / 0.5 / 7.3은 **2026년도 기준**이며 담당자가 2026-09-13에 확인했다. 목표는 연 단위로 다시 설정되므로 다른 연도 데이터에 그대로 적용하지 말 것.

*관련어: 당일검사완료율 · 용접불량률 · 정도불량률 · 3대 지표 · KPI 목표값 · 98% · 0.5 · 7.3 · 개선 레버*

### 당일검사완료율의 실제 계산 구조 — 분모는 부위 수가 아니라 검사 시행 횟수  `kpi-02` · 등급 C

재검이 원 검사와 **별도 행으로 쌓이므로** (사내확정 2026-09-12), 한 부위가 여러 행을 만든다.

| 케이스 | 남는 행 | A행 | R행 | 그 부위의 기여 |
|---|---|---|---|---|
| 1차 합격 | A | 1 | 0 | 1/1 |
| 1차 R → 재검 A | R, A | 1 | 1 | 1/2 |
| 1차 R → 재검 R → 3차 A | R, R, A | 1 | 2 | 1/3 |

당일검사완료율 = A/(A+R)×100 의 분모는 "검사 부위 수"가 아니라 **"검사 시행 횟수"** 다. R이 한 번 나면 그 부위는 행을 2개 만들고, 재검을 두 번 가면 3개 만든다. 지표를 "100건 중 98건 합격"으로 읽으면 틀린다.

*관련어: 당일검사완료율 분모 · 검사 시행 횟수 · 재검 별도 행 · A/(A+R)*

### 목표 98%는 "1차 R률 2.04% 이하"로 번역된다 — 단 검증 전, 단독 보고 금지  `kpi-03` · 등급 ?

부위 N개가 결국 모두 합격하고 그중 k개가 1차 R 후 1회 재검으로 통과한다고 두면, A행 = N, R행 = k, 지표 = N/(N+k).

```
N/(N+k) ≥ 0.98  ⇔  k/N ≤ 0.0204
```

즉 **당일검사완료율 98% ≈ 1차 검사 불합격률 2.04% 이하.** 100건 검사해서 1차에서 2건까지만 R이면 턱걸이(98.04%), 3건이면 97.09%로 미달. 2회 이상 재검이 섞이면 R행이 더 늘어 기준이 더 빡세진다. 현장에 목표를 설명할 때 "98%"보다 **"100건 중 1차에서 2건까지만 R"** 이 전달이 빠르다.

**이 번역은 아직 검증되지 않았다.** 전제 두 개 — ① 재검 행의 용도결정이 A로 찍히는가 ② 행이 1차인지 재검인지 데이터로 구분되는가 — 가 사내 확인 대기다. ②가 없으면 1차 R률 자체를 셀 수 없어 이 해석을 검증할 방법이 없다. 목표 98%가 2026년도 기준이라는 점만 확정됐다. **확인 전까지 2.04%를 보고서에 단독으로 쓰지 말 것.** 질문을 받으면 "근사 해석이며 검증 전"이라고 답할 것.

*관련어: 2.04% · 1차 R률 · 1차 검사 불합격률 · 98% 의미 · N/(N+k)*

### 일별 신호등은 경보용, 판단은 월 누계로 — R일과 재검일이 갈려서 일별 변동이 부푼다  `kpi-04` · 등급 G

1차 R과 재검 A는 **다른 날**에 잡힌다. 같은 부위의 손실(R일)과 회복(재검일)이 분리되므로 **일별 지표 변동이 실제 품질 변동보다 크게 나타난다.** 일별 신호등이 bad로 떨어진 날 중 상당수는 그날 품질이 나빠진 게 아니라 **그날 R이 몰린 것**이고, 며칠 뒤 재검 A로 되올라온다.

→ **일별 신호등은 경보용, 판단은 월 누계로.**

같은 결론이 작업량(W.L) 쪽에도 있다 — 공기 긴 블록은 완료 시점에 작업량이 일괄 인식돼 주간 생산성 착시를 만든다. 원인은 다르다: 작업량은 완료 일괄 인식 때문이고, 검사 지표는 R과 재검의 날짜 분리 때문이다. 둘 다 "주차 변동보다 월 집계 우선"으로 귀결된다.

*관련어: 일별 변동 · 월 누계 · 신호등 bad 이유 · 일별 지표 증폭*

### 목표값은 연 단위로 바뀐다 — 연도 비교·소급 판정·연초 전환의 함정 3종  `kpi-05` · 등급 C

**98% / 0.5 / 7.3은 2026년도 기준값이다** (사내확정 2026-09-13). 목표가 해마다 다시 설정된다는 뜻이고, 세 가지가 따라온다.

| 함정 | 왜 틀리나 | 대응 |
|---|---|---|
| 연도 간 **달성률** 비교 | 목표선이 움직이므로 같은 실적도 연도마다 달성률이 달라진다 | 연도 비교는 **원지표(raw %)** 로. 달성률은 같은 해 안에서만 |
| 과거 데이터에 **신호등 소급 적용** | 2025년 실적에 2026년 목표를 씌우면 없던 bad가 생긴다 | 아카이브 스냅샷에 **그 해의 목표값을 함께 저장** |
| 연초 전환 구간 | 1월에 전년 12월 데이터를 보면 어느 목표를 쓸지 모호해진다 | **데이터 기준일의 연도**로 목표를 조회 (조회 시점이 아니라) |

코드 쪽 함의: 목표값을 하드코딩하면 연초에 여러 파일을 고쳐야 하고 반드시 하나를 빠뜨린다. **연도를 키로 갖는 설정 1곳**에 몰고, 데이터 기준일에서 연도를 뽑아 조회한다.

```python
TARGETS = {
    2026: {"당일검사완료율": 98.0, "용접불량률": 0.5, "정도불량률": 7.3},   # 사내확정
    2025: {"당일검사완료율": None, "용접불량률": None, "정도불량률": None},  # 확인 대기
}
```

전년(2025) 목표값과 연도별 목표 이력 관리처는 사내 확인 대기다. 채우기 전까지 전년 대비 비교 화면을 만들지 말 것. 신호등 배수(0.97/1.30)도 연 단위인지 고정인지는 확인 대기다.

*관련어: 연도별 목표 · 목표값 연 단위 · 달성률 비교 · 소급 판정 · 연초 전환 · TARGETS 설정*

### 신호등 판정 규칙 — 상향 지표 0.97, 하향 지표 1.30 (사내확정)  `kpi-06` · 등급 C

배수 0.97 / 1.30은 담당자가 2026-09-13에 확인했다.

- **상향 지표**(당일검사완료율): `v ≥ 목표` → good / `v ≥ 목표×0.97` → warn / 그 외 bad
- **하향 지표**(용접불량률·정도불량률): `v ≤ 목표` → good / `v ≤ 목표×1.30` → warn / 그 외 bad
- 색상: good `#2c8a5f` / warn `#c89010` / bad `#b3402a`

예: 당일검사완료율 목표 98%면 good ≥ 98, warn ≥ 95.06, bad < 95.06. 용접불량률 목표 0.5면 good ≤ 0.5, warn ≤ 0.65, bad > 0.65.

배수가 연 단위로 바뀌는지 고정인지는 사내 확인 대기다.

*관련어: 신호등 · good warn bad · 0.97 · 1.30 · 신호등 배수 · 신호등 색상*

### 기성·조업도·난이도 산식 — 근무일 보정 필수, 블럭당 난이도를 쓸 것  `kpi-07` · 등급 G

```
기성금액     = 완료블럭 수 × 블럭당 금액
일당 기성    = 기성금액 ÷ 근무일수          ← 근무일 편차 제거 필수
공수 효율    = 기성금액 ÷ 공수
블럭당 난이도 = 난이도 점수합 ÷ 완료블럭 수   ← 일당 난이도보다 이걸 쓸 것
조업도       = t/man·day (EPC 처리량 / 기준 처리량)
연간 M/H    = (연간 발생 횟수 + 월 재작업 × 12) × 1회 소요 분 ÷ 60 × 인원
```

휴가·조업일수 차이가 있으면 근무일 기준으로 보정한 뒤 비교한다. 근무일수의 기준(달력? 과별 실제 조업일?)은 사내 확인 대기.

난이도 점수에 들어가야 할 항목 후보: 조립 단계(소/중/대), 곡·평 구분, 반전 횟수, 밀폐구역 유무, 위보기 용접 비율, 핀지그 셋업 여부. 현재 산식의 실제 구성 항목과 블럭당 금액의 출처, 완료 판정 시점은 모두 사내 확인 대기다.

*관련어: 기성금액 · 일당 기성 · 공수 효율 · 블럭당 난이도 · 조업도 · t/man·day · 연간 M/H · 근무일 보정*
