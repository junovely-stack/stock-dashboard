# 조선소 조립공정 지식베이스

조립4과 생산관리 업무에 쓰는 도메인 지식 저장소. 사람이 읽는 용도 + Claude·사내 AI 에이전트에 컨텍스트로 물려주는 용도 겸용.

## 파일 구성

| 파일 | 내용 | 갱신 주기 |
|---|---|---|
| `조선소_조립공정_지식_REV02.md` | 본문. 공정 메커니즘·공종·설비·데이터 매핑 | REV 단위 |
| `용어사전_조립공정_REV02.csv` | 용어 135항목 → 한자/영문 → 정의 → 검증등급 (UTF-8 BOM) | 본문과 동시 |
| `검증로그_REV02.md` | 검증 등급 판정 근거 + 확인 질문 36건(35 대기 / 1 확정) | 확인 답변 올 때마다 |
| `tools/검사데이터_구조진단_REV01.py` | 검사 데이터 스키마 자동 진단 → D1·D2·D7·D8 회신안 생성 | 도구 자체 REV |

## 검증 등급 (본문·사전 공통)

| 표기 | 뜻 | 취급 |
|---|---|---|
| `[E]` | 외부검증 — 공개자료 2건 이상 또는 규칙·특허·논문으로 교차확인 | 그대로 인용 가능 |
| `[G]` | 업계통용 — 업계에서 일반적으로 통하지만 출처가 단일하거나 구두 전승 | 사내 문서에 쓸 때 한 번 확인 |
| `[C]` | 사내확정 — 담당자 확인으로 확정된 사내 사실 (검증로그에 확인일 기록) | 그대로 사용 가능 |
| `[?]` | 사내확인필요 — 야드·과·호선마다 다름 | **확정 전 보고서·지표에 쓰지 말 것** |

`[?]` 항목에 숫자를 채워 넣지 않는다. 빈칸 또는 "확인 대기"로 둔다.

## 갱신 규칙

1. 새로 쓰지 말고 **직전 REV 위에 덧붙인다.** 압축하면서 디테일 날린 전례 있음.
2. 등급 승격은 `검증로그`에 근거를 남긴 뒤 본문 표기를 바꾼다. 사내 확인으로 풀린 항목은 `[?]` → `[C]`(확인일 병기), 외부 자료로 뒷받침되면 `[G]` → `[E]`.
3. 사내 실제 코드·MES 스키마와 이 문서가 다르면 **실제 쪽이 정답.** 이 문서를 근거로 코드를 판단하지 말 것.
4. 호선명·선주명·작업자 실명·사번은 이 저장소에 넣지 않는다.

## 확인 질문을 스크립트로 대신 푸는 법

검증로그의 D1·D2·D7·D8은 눈으로 컬럼을 뒤지지 않고 도구로 답할 수 있다.

```
py knowledge/tools/검사데이터_구조진단_REV01.py --selftest   # 더미로 동작 확인 (엑셀 불필요)
py knowledge/tools/검사데이터_구조진단_REV01.py              # 상단 FILES에 실파일 경로 넣고 실행
```

정상동작 확인: `--selftest`에서 CASE-A는 "D7 해결 가능", CASE-B는 "D7 미해결"로 갈리고 마지막 줄이 `정상`이면 OK.

실행하면 `[7] 검증로그 자동 회신안` 블록이 나온다. 그걸 그대로 검증로그 답변 칸에 붙이면 된다.
DRM 보호 파일은 `USE_XLWINGS = True`로 두면 숨긴 Excel 인스턴스에서 read-only로 읽고 종료한다.
작업자 실명·사번으로 의심되는 컬럼은 샘플값이 자동 마스킹되므로 리포트를 사내 공유해도 된다.

## AI에 물릴 때

`조선소_조립공정_지식_REV02.md` 전체 + `용어사전` CSV를 붙이고 프롬프트에 한 줄:
> 이 지식의 `[?]` 표기 항목은 미확정이다. 해당 항목에 대해서는 값을 추정하지 말고 "확인 필요"로 답하라.
